3. LLM 调用详细流程 (Step 3)
1
构建工具列表
ContextOrchestrator.build_tools_for_llm()
内置工具: memory_search, file_read, web_search, etc.
Skill 工具: 动态获取的技能
MCP 工具: 外部工具连接
格式: OpenAI function calling schema
↓
2
移除已自动执行工具
如果工具已自动执行，从列表中移除
条件: tool_decision == "auto_executed"
过滤: tools_for_llm = [t for t if name != executed_tool]
↓
3
LLM 调用
Agent Loop 或 Legacy fallback
流式: loop.predict_step(context, tools, stream=True)
非流式: loop.predict_step(context, tools, stream=False)
Legacy: llm_client.chat(context)
失败时 fallback 到 legacy
↓
4
自动续写
_auto_continue() 处理截断续写
条件: finish_reason == 'length'
续写提示: _build_continue_hint()
护栏: 重叠检测、语义循环检测、工具调用循环
最大轮次: 100 轮
↓
5
文本工具调用

执行工具并返回结果

7. 潜在风险点（需监控）
当前风险点（4个）
1. Agent Loop 可用性 - Agent Loop 系统不可用时的 fallback 逻辑
风险：Legacy fallback 可能丢失功能（如工具调用、思考过程）
影响：LLM 调用失败时降级到传统模式
状态：需监控
2. 异步操作超时 - 工具自动执行超时处理
风险：超时后状态可能不一致（tool_decision="timeout"）
影响：工具执行超时，用户可能收到不完整回复
状态：需监控
3. 记忆检索降级 - UnifiedRetriever 不可用时的 MoE 降级
风险：降级路径可能影响检索质量
影响：记忆检索可能不完整
状态：需监控
4. 结晶经验检索失败 - PatternCrystallizer 异常处理
风险：异常时跳过结晶经验注入，可能影响回复质量
影响：缺少结晶经验注入，回复可能不够精准
状态：需监控
