## Fallback 机制

```
┌─────────────────────────────────────────────────────────────┐
│                    Fallback Chain                            │
├─────────────────────────────────────────────────────────────┤
│  1. MOSSNanTTS (本地推理，高质量)                            │
│     ↓ 失败                                                  │
│  2. EdgeTTS (在线服务，中文效果好)                           │
│     ↓ 失败                                                  │
│  3. MockTTSSimple (模拟引擎，总是可用)                       │
└─────────────────────────────────────────────────────────────┘
```

## 配置选项

### TTSConfig 配置类
```python
class TTSConfig(BaseModel):
    engine: Literal["edge-tts", "moss-nano", "mock", "auto"] = "auto"
    voice: str = "zh-CN-XiaoxiaoNeural"
    rate: str = "+0%"
    volume: str = "+0%"
    model_path: Optional[str] = None
    tokenizer_path: Optional[str] = None
    auto_download: bool = True
    fallback_enabled: bool = True
```

### 引擎选择策略
1. **auto模式**: 按fallback链尝试所有引擎
2. **指定引擎**: 直接初始化指定引擎
3. **回退机制**: 失败时自动切换到下一个引擎

## 错误处理

### 初始化失败处理
1. **依赖缺失**: 捕获ImportError，记录日志
2. **初始化异常**: 捕获Exception，记录日志
3. **回退触发**: 自动尝试下一个引擎

### 合成失败处理
1. **合成异常**: 捕获Exception，返回空数据
2. **回退合成**: 尝试fallback链中的下一个引擎
3. **最终失败**: 所有引擎都失败，返回空数据

## 性能考虑

### MOSSNanTTS
- **优点**: 本地推理，无网络延迟，高质量
- **缺点**: 需要GPU或高性能CPU，模型下载大

### EdgeTTS
- **优点**: 免费，中文效果好，无需GPU
- **缺点**: 需要网络连接，有延迟

### MockTTSSimple
- **优点**: 无依赖，总是可用，快速
- **缺点**: 音频质量低，仅用于测试

## 扩展点

### 添加新引擎
1. 继承TTSBase基类
2. 实现initialize()和synthesize()方法
3. 在TTSManager中注册新引擎
4. 更新FALLBACK_CHAIN

### 自定义配置
1. 通过TTSConfig配置引擎参数
2. 支持环境变量配置
3. 支持配置文件加载
