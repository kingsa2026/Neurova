#   - 本文件是 requirements.txt 的"轻量核心子集"，供 GitHub Actions 使用。
#   - 刻意排除体积大 / 需本地模型 / 需显示器的重依赖（sentence-transformers、
#     transformers、torch、soundfile、huggingface_hub、sentencepiece、edge-tts、
#     pillow、pyautogui、playwright）。
#     **例外一：numpy（2026-10-23 起）。** 受保护子集里有判据走真实向量原语与真实分词

#     而不是"代码坏了"，CI 里两者同形，红得说不清是谁的问题。
#     **例外二：onnxruntime / tokenizers（2026-10-25 起）。** 与 numpy 同一根因：引擎
#     `initialize_sync()` 在它们缺席时返回 False、`encode()` 走零向量兜底，而联想召回
#     基线 / 线索向量通道 / 长时记忆基线 / 写侧补嵌入那几族判据全部建立在"向量有意义"
#     之上且**刻意不 skip**；把判据改成 skip 等于把这道门关掉（教义第 2 条）。
#     模型权重随仓入库（`models/embedding/bge-small-zh-v1.5`），故缺的从来只是这几个包。
#     transformers / sentencepiece 仍不声明：实测逐件屏蔽（meta_path 拦截）后，
#     `tokenizer.json` 直读即成功，两者体积大且连带 torch。
#     **三个例外都只在本文一份声明**（正文其余处不再重复行，见下文的声明面）。
#   - 上述被排除依赖在代码中均为"惰性/try 降级"导入，缺席时模块仍可加载；
#     它们在 scripts/ci_static_gate.py 的 KNOWN_OPTIONAL_DEPS 中登记，
#     导入巡检会记为 OPTIONAL-SKIP（优雅降级），不算失败。
#   - 如需完整功能（TTS/ASR/Embedding/NeRF/Computer Use），请改用稳定版 Python
#     （建议 3.11–3.13）安装完整 requirements.txt。
