严重断点 — 数据流完全中断

#2
Auth 认证系统未实现
neurova/api/endpoints/auth.py — 多处 TODO
登录验证、用户注册、验证码发送、验证逻辑、登出(Token黑名单)全部标记为 TODO，直接返回成功。任何人可以访问系统。
#4
Agent 权限检查缺失
neurova/api/endpoints/chat.py:75 — _user_can_access_agent() 直接返回 True
任何经过认证的用户都可以访问任何 Agent，没有所有权或角色检查。
#9
内置工具多个桩实现
neurova/tool_executor.py:497-530
Computer Use 的 5 个方法 (screenshot/click/type/scroll/shell) 全部返回"未初始化"。memory_search 返回模拟空列表。emotion_analyze 固定返回 neutral。CLI 工具返回"未实现"。
#10
ToolRouter 签名不匹配 (运行时 TypeError)
agent/loops/base.py:113 → tool_layers/tool_router.py:115
BaseAgentLoop 传入 (tool_name, params, agent_id, user_id) 四个参数，但 ToolRouter.execute 只接受 (tool_name, params)。导致 TypeError，ToolRouter fallback 路径永远失败。
#14
ContextBuilder.compress_if_needed() 方法不存在
neurova/context/orchestrator.py:474
当 ContextPool 未启用时，调用 context_builder.compress_if_needed(context) 会抛出 AttributeError。非 ContextPool 路径完全断裂。
#17
认知闭环协调器所有核心方法为空
neurova/knowledge/integration/cognitive_loop.py:382-428
_knowledge_to_memory / _knowledge_to_evolution / _handle_memory_miss / _check_gap_discovery / _execute_reflection / _evolution_feedback 全部只有 pass + 日志。
#19
记忆-知识库双向同步为空壳
neurova/knowledge/integration/memory_sync.py:66-90
sync_memory_to_knowledge() 和 sync_knowledge_to_memory() 只记录日志，synced_count 始终为 0。
#3
eval() 代码注入风险
neurova/router.py:218
Skill 请求路由中使用 eval(params_str) 解析用户输入参数，存在严重的代码注入安全风险。

警告 — 部分实现或潜在问题

#1
CORS 配置过于宽松
neurova/api/middleware.py:164 — allow_origins=["*"]
允许所有来源的跨域请求，生产环境应限制。同时 JWT Secret 使用硬编码默认值。
#5
ToolMemory 条件反射异常静默
neurova/agent/chat_pipeline.py:364
_record_tool_failure() 中 except Exception: pass 完全静默。Agent 关闭异常也被 pass 吞没。
#6
Token 估算不一致 (4种实现)
分散在 UnifiedContextInjector / ContextPoolUtils / Message / SmartContextCompressor
同一段文本在不同模块的 Token 估算差异可达 4-8 倍，导致预算控制和压缩行为不一致。
#7
Deprecated 方法仍在使用路径中
agent_core.py — _chat_normal() / _chat_stream() 标记 DEPRECATED v5.0
ChatPipeline 的 _call_legacy() 仍然调用这些方法作为 fallback，但方法可能不完全兼容新架构。
#11
ToolOrchestrator "并行执行"实际为顺序
neurova/tool_layers/tool_orchestrator.py:152-158
注释承认 "简化为顺序执行"。目标解析使用简单关键词匹配而非 LLM。
#13
ContextPool SemanticMatchDrawer 截断参数错误
neurova/context_pool.py:1183
传入不存在的 id 参数给 ContextInput，导致 TypeError。仅在 Token 超预算截断时触发。
#15
ContextCacheManager 与 ContextPersistence 接口不匹配
neurova/context_cache.py:668-673
调用 save_context_from_data() 缺少 session_id 参数，缓存脏数据写入磁盘会异常。
#16
记忆温度更新机制失效
neurova/agent_core.py:1465-1471
_update_memory_temperature() 为空方法，try/except 中只有 pass。记忆温度不会实际更新。
#21
Voice Pipeline 部分依赖外部
neurova/voice_pipeline.py
架构完整但部分环节依赖 Twilio 等外部服务。
✅ 已诊断: voice_pipeline.py 不依赖 Twilio，所有 4 个依赖均为内部模块 (ASR/TTS Manager, VoiceContextModule, VoiceMemoryBridge)。Twilio 依赖在 channels/voice.py（独立通道适配器），不影响 voice_pipeline。该模块仍在 agent_core.py 中活跃使用（ASR 处理）。断点描述不准确，已修正。

未集成 — 已设计但未接入主流程

✅ 已修复: 添加依赖注入 configure() 方法 + StepStatus 状态跟踪 + 13步全量覆盖。不可用时显式 SKIPPED 而非静默跳过。
