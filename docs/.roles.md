# Selling Partner API Roles

Learn how to use roles in the Selling Partner API.

<<glossary:Role>>s are the mechanism by which the Selling Partner API (SP-API) determines whether a <<glossary:developer>> or <<glossary:application>> has access to an operation or resource. Roles protect access to <<glossary:personally identifiable information>> (PII) and other sensitive data, and ensure that developers only access data that their application requires.

As a developer, you must request and qualify for a particular role to gain access to the operations and resources that the role provides. If you call an operation for which you don't have the required roles, you get a 403 error.

## Choose your roles

Use the following topics to identify which role you need for each SP-API operation and type:

* [Role Mappings for Operations](https://developer-docs.amazon.com/sp-api/docs/role-mappings)
* [Role Mappings for Types](https://developer-docs.amazon.com/sp-api/docs/role-mappings-for-types)

After you know which roles you need, you request them through your developer profile. Amazon evaluates the information you submit and approves or denies your request. If denied, you can address the reason for the denial and then resubmit your profile.

### Add your approved roles to your application

When you [register your SP-API application](https://developer-docs.amazon.com/sp-api/docs/registering-your-application), you can choose roles from among those that you were approved for in your developer profile. If the role that you need is missing, you must update the roles in your developer profile to include the new role, and then resubmit your profile for evaluation by Amazon. If you are approved, the added role will be available to select for your application.

> 📘 Note
>
> If you published a hybrid SP-API application, you must relist your application before reauthorization.

To add a new role:

1. Go to your developer profile and submit the role that you want to add.
2. After your [developer profile is approved](https://developer-docs.amazon.com/sp-api/docs/checking-the-status-of-your-request-to-register-as-a-developer), go to your application configuration and [apply the newly approved role](https://developer-docs.amazon.com/sp-api/docs/updating-your-application-information) to your application. Save the changes and re-list the application.
3. After the application is approved, [get new authorizations](https://developer-docs.amazon.com/sp-api/docs/authorizing-selling-partner-api-applications) to generate a new <<glossary:refresh token>> that grants access to the API operations, reports, feeds, and notifications that the new role provides.

## Role definitions

In the following sections, *Restricted* means that the role requires sensitive information, which might include personally identifiable information (PII). For these roles, you must provide additional information about your data use and security controls.

### Account Information Service Provider

The Account Information Service Provider (AISP) role provides access to information about the Amazon Selling Partner account, including information about the seller's business and the Amazon stores where the seller account is active. You can use this role to view payment methods and financial events for the seller.

* **Role available to sellers?** Yes

* **Role available to vendors?** No

<details>
  <summary>Select for examples of operations that require this role.</summary>

* The `getAccount` operation of the [Sellers API v1](https://developer-docs.amazon.com/sp-api/reference/sellers-v1), which gets information about a seller account and its Amazon stores.
* The `getPaymentMethods` operation of the [Transfers API v2024-06-01](https://developer-docs.amazon.com/sp-api/reference/transfers-v2024-06-01), which returns a list of payment methods for the seller.

</details>

### Amazon Fulfillment

The Amazon Fulfillment role provides access to Amazon fulfillment operations and shipping services such as Fulfillment by Amazon (FBA) and Amazon Fulfillment Network (AFN). You generally use this role for FBA sales reports, order tracking reports, and operations related to order fulfillment.

* **Role available to sellers?** Yes

* **Role available to vendors?** Yes

<details>
  <summary>Select for examples of operations that require this role.</summary>

* The `createReport` operation of the [Reports API v2021-06-30](https://developer-docs.amazon.com/sp-api/reference/reports-v2021-06-30), when you request the [FBA Fee Preview](https://developer-docs.amazon.com/sp-api/docs/report-type-values-fba#fba-fee-preview-report) report. This report contains the estimated Amazon selling and fulfillment fees for the seller's FBA inventory with active offers.
* The `getSubscription` operation of the [Notifications API v1](https://developer-docs.amazon.com/sp-api/reference/notifications-v1), when you subscribe to [`FBA_OUTBOUND_SHIPMENT_STATUS`](https://developer-docs.amazon.com/sp-api/docs/notification-type-values#fba_outbound_shipment_status) notifications. These notifications signify when Amazon creates or cancels a Fulfillment by Amazon shipment for a seller.
* The `listShipmentItems` operation of the [Fulfillment Inbound API v2024-03-20](https://developer-docs.amazon.com/sp-api/reference/fulfillment-inbound-v2024-03-20), which returns a list of packages in a shipment.
* The `createFeed` operation of the [Feeds API v2021-06-30](https://developer-docs.amazon.com/sp-api/reference/feeds-v2021-06-30), when you submit a `POST_FBA_INBOUND_CARTON_CONTENTS` feed. This feed lets you submit carton content information when shipping inventory to Amazon’s fulfillment network.

</details>

* **Role available to sellers?** Yes

* **Role available to vendors?** Yes

<details>
  <summary>Select for examples of operations that require this role.</summary>

* The `listInventory` operation of the [Amazon Warehousing and Distribution API v2024-05-09](https://developer-docs.amazon.com/sp-api/reference/amazon-warehousing-and-distribution-v2024-05-09), which returns inventory levels and states for products in AWD.
* The `getInboundShipment` operation of the [Amazon Warehousing and Distribution API v2024-05-09](https://developer-docs.amazon.com/sp-api/reference/amazon-warehousing-and-distribution-v2024-05-09), which returns shipment details such as the status and received quantities for reconciliation.

</details>

Operations that require this role use PII to enable shipping. You generally use this role to request order reports, order tracking reports, EasyShip, and for operations that relate to shipping orders placed on Amazon.

* **Role available to sellers?** Yes

* **Role available to vendors?** Yes

<details>
  <summary>Select for examples of operations that require this role.</summary>

* The `getOrders` operation of the [Orders API v0](https://developer-docs.amazon.com/sp-api/reference/orders-v0), which returns a list of orders and order information based on criteria that you specify.
* The `createReport` operation of the [Reports API v2021-06-30](https://developer-docs.amazon.com/sp-api/reference/reports-v2021-06-30), when you request the `GET_FLAT_FILE_ORDER_REPORT_DATA_SHIPPING` report.
* The `createFeed` operation of the [Feeds API v2021-06-30](https://developer-docs.amazon.com/sp-api/reference/feeds-v2021-06-30), when you submit a `POST_ORDER_FULFILLMENT_DATA` feed. This feed allows your system to update Amazon's system with order fulfillment information.

</details>

The Inventory and Order Tracking role provides access to operations that analyze and manage inventory. You generally use this role to get FBA sales reports, order tracking reports, and operations related to orders, vendor orders, sales order metrics, and inventory management. Operations that require this role do not use PII required to ship an order. Rather, this role is for applications that track shipments.

* **Role available to sellers?** Yes

* **Role available to vendors?** No

<details>
  <summary>Select for examples of operations that require this role.</summary>

* The `getOrderMetrics` operation of the [Sales API v1](https://developer-docs.amazon.com/sp-api/reference/sales-v1), which returns aggregated order metrics.
* The `createReport` operation of the [Reports API v2021-06-30](https://developer-docs.amazon.com/sp-api/reference/reports-v2021-06-30), when you request the `GET_MERCHANT_LISTINGS_DATA` report. This report returns detailed active listings.

</details>

* **Role available to vendors?** No
