### 一、严重BUG（Critical）

#### BUG-001: 无限递归函数调用
**位置**: `api/endpoints/chat.py` 第33-35行
```python
def _get_request_id(req: Request) -> Optional[str]:
    """安全获取 request_id"""
    return _get_request_id(req)  # ❌ 无限递归调用自身
```
**问题**: 函数内部直接调用自身，导致无限递归，会引发 `RecursionError`
**影响**: 所有调用此函数的接口都会崩溃（`/chat`, `/chat/stream`, `/chat/history`）
**建议修复**:
```python
def _get_request_id(req: Request) -> Optional[str]:
    """安全获取 request_id"""
    return getattr(req.state, "request_id", None)
```

#### BUG-002: 类未实例化导致方法调用失败
**位置**: `agent.py` 第182行
```python
self.temperature_engine = TemperatureEngine  # ❌ 赋值类而非实例
```
**问题**: `temperature_engine` 被赋值为类本身而非类的实例，导致后续调用实例方法时失败
**影响**: 记忆温度更新功能完全失效
**建议修复**:
```python
self.temperature_engine = TemperatureEngine()

    if get_origin(annotation):
        return str(annotation)
    return "Any"
```
