## 四、团队协作机制

### 每日站会
- **时间**: 每天上午10:00
- **内容**: 汇报昨日进度、今日计划、遇到的问题
- **工具**: 飞书会议 + 进度跟踪表更新

### 进度跟踪
- **文件**: `docs/dev_progress/progress_tracker.md`
- **更新频率**: 每天至少一次
- **责任人**: 每个任务的负责人

### 代码审查
- **要求**: 所有代码必须通过单元测试
- **流程**: 提交PR → 自动测试 → team-lead审查 → 合并
- **标准**: PEP 8规范、类型注解、文档字符串

### 文档要求
- **模块设计文档**: 每个模块必须有设计文档
- **每日报告**: 每天更新 `daily_reports/YYYY-MM-DD.md`
- **API文档**: 所有API必须有文档
- **测试报告**: 每个模块必须有测试报告
