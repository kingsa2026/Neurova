## 1. 项目概览

Neurova 是"有温度的智能体"AI Agent 框架：17 维记忆分类系统、温度遗忘曲线（0-100°C）、四层 17 情绪中枢、CogArch 2.0 认知架构。后端 FastAPI + SQLite + LiteLLM 多模型路由（深度模块模式 + agent_ref 依赖注入），前端 Vue 3 + TypeScript + Pinia + Ant Design Vue，移动端 HarmonyOS ArkTS，14 种通信渠道适配器，Neurflow 可视化工作流引擎。

- 后端：`neurova/`（FastAPI + SQLite + LiteLLM，Python，深度模块模式 + agent_ref 依赖注入）
- 前端：`NeurUI/`（Vue 3 + TypeScript + Vite + Pinia + Ant Design Vue）
- 移动端：`NeurovaHarmony/`（HarmonyOS ArkTS 应用）
- 测试：`tests/`（pytest：unit / integration / e2e / performance）
- 数据库：SQLite（详见第 5 节与 [数据库图谱.md](数据库图谱.md)）
- 交互式图谱：`.understand-anything/knowledge-graph.json`（可用 /understand-dashboard 可视化）
