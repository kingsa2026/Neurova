# Neurova 项目综合解决方案

## 问题 1: JWT 登录失败 (500 Internal Server Error)

### 状态
✅ **已诊断** - 根本原因已找到
✅ **已修复** - requirements.txt 已更新
⏳ **待执行** - 需要服务器端操作

### 根本原因
`neurova/api/auth.py` 第25行使用 `import jwt`（PyJWT 包），但 `requirements.txt` 中只包含了 `python-jose`（提供 `jose` 模块，不提供 `jwt` 模块）。

### 已完成的修复
1. ✅ 在 `requirements.txt` 中添加 `PyJWT>=2.8.0`
2. ✅ 创建 `test_jwt_fix.py` 验证脚本
3. ✅ 创建 `fix_jwt_import.py` 诊断脚本
4. ✅ 创建 `JWT修复指南.md` 详细说明

### 需要手动执行的步骤

#### 步骤 1: 安装 PyJWT
```bash
# 在服务器上运行
pip install PyJWT>=2.8.0

# 或者重新安装所有依赖
pip install -r requirements.txt
```

#### 步骤 2: 重启后端服务器
```bash
# 方法 1: 使用启动脚本
python start_server.py

# 方法 2: 直接使用 uvicorn
uvicorn neurova.api.app:create_app --host 0.0.0.0 --port 9527 --reload
```

#### 步骤 3: 验证修复
```bash
python test_jwt_fix.py
```

## 故障排除

### JWT 问题仍然存在
1. 检查 Python 环境: `python --version`
2. 确认 PyJWT 安装: `pip show PyJWT`
3. 检查服务器日志
4. 确保服务器完全重启（不是热重载）

### GitHub 发布失败
1. 检查 Token 权限: 需要 `repo` 权限
2. 确认仓库名称正确: `kingsa2026/Neurova`
3. 检查网络连接
4. 查看错误信息

### 服务器无法启动
1. 检查端口占用: `netstat -ano | findstr :9527`
2. 检查依赖安装: `pip list`
3. 查看详细错误日志
