## 二、UI 设计系统

### 2.1 设计系统推荐（基于 ui-ux-pro-max）

**模式**: Minimal & Direct + Demo  
**样式**: Flat Design（扁平化设计）  
**字体**: Plus Jakarta Sans（友好、现代、专业）

**颜色方案**:
- **主色**: `#6366F1`（靛蓝）
- **次要色**: `#818CF8`（浅靛蓝）
- **CTA 色**: `#10B981`（翡翠绿）
- **背景**: `#F5F3FF`（浅紫白）
- **文本**: `#1E1B4B`（深靛蓝）

**关键效果**:
- 无渐变/阴影，简单悬停效果
- 快速加载，干净过渡（150-200ms ease）
- 最小化图标使用

**避免的反模式**:
- 复杂的入职流程
- 杂乱的布局

### 2.2 图表推荐

| 数据类型 | 推荐图表 | 备选方案 | 库推荐 |
|----------|----------|----------|--------|
| 性能 vs 目标 | 仪表图/子弹图 | 拨盘、温度计 | D3.js, ApexCharts |
| 层次比例 | 旭日图 | 树状图、圆形填充 | D3.js, Recharts |
| 累积变化 | 瀑布图 | 堆叠柱状图 | ApexCharts, Highcharts |
| 比例/百分比 | 华夫饼图 | 象形图、100% 堆叠柱 | D3.js, React-Waffle |
| 股票/交易 OHLC | K 线图 | OHLC 柱状图 | Lightweight Charts |

### 2.3 UX 最佳实践

**动画与过渡**:
- 加载状态：使用骨架屏或旋转器
- 连续动画：仅用于加载指示器
- 懒加载：延迟加载非首屏内容
- 字体加载：使用 `font-display: swap`

**交互反馈**:
- 操作 > 300ms 时显示加载指示器
- 所有可点击元素添加 `cursor-pointer`
- 悬停状态提供清晰视觉反馈
- 过渡时间 150-300ms

## 四、技术实现细节

### 4.1 组件库选择

**UI 组件库**: Ant Design Vue  
**图表库**: ECharts + ApexCharts  
**图谱库**: D3.js + vis.js  
**代码高亮**: highlight.js  
**图标库**: Heroicons + Lucide

### 4.2 状态管理

**Pinia Stores**:
- `useAgentStore` - Agent 状态管理
- `useModelStore` - 模型状态管理
- `useChatStore` - 对话状态管理
- `useCollaborationStore` - 协作状态管理
- `useAnalyticsStore` - 分析数据管理

### 4.3 API 集成

**API 模块**:
- `api/agents.ts` - Agent 相关 API
- `api/models.ts` - 模型相关 API
- `api/chat.ts` - 对话相关 API
- `api/collaboration.ts` - 协作相关 API
- `api/analytics.ts` - 分析相关 API

### 4.4 性能优化

**优化策略**:
1. **代码分割**: 使用动态导入
2. **懒加载**: 路由级别懒加载
3. **缓存**: Pinia store 缓存
4. **压缩**: Gzip 压缩
5. **CDN**: 静态资源 CDN
