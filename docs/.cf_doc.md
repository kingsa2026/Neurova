# Customer Feedback API

Programmatically retrieve insights from customer reviews and returns.

The Selling Partner API for Customer Feedback (Customer Feedback API) provides insights from customer reviews and returns. This API provides the same information as the Product Opportunity Explorer (OX) on Seller Central and Vendor Central. Review insights are available at the <<glossary:ASIN>> and <<glossary:browse node>> level. Return insights are only available at the browse node level.

The Customer Feedback API is available in the following [Amazon stores](https://developer-docs.amazon.com/sp-api/docs/marketplace-ids):

* United States
* United Kingdom
* France
* Italy
* Germany
* Spain
* Japan

The data provided by the Customer Feedback API is refreshed weekly. This API is only available in English.

## Use cases

The following use case examples are available for the Customer Feedback API v2024-06-01:

* [Get Feedback Insights for an ASIN](https://developer-docs.amazon.com/sp-api/docs/get-feedback-insights-asin): ASIN insights include the most positive and the most negative review topics for a specific ASIN. You can sort topics by the number of mentions and the effect they have on the star rating. Month-on-month trends are also available.
* [Get Feedback Insights for a Browse Node](https://developer-docs.amazon.com/sp-api/docs/get-feedback-insights-browse-node): Browse node insights include the most positive and negative review and return topics for a browse node. Topics can be sorted by number of mentions and the effect on star rating they have. Month-on-month trends are also available. Review insights have customer snippets, while return insights have granular topic classifications.
