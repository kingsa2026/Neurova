## 修复的 Bug

### 1. SkillRecord 数据模型字段不匹配
- **问题**: `register_skill` 方法传递了 `models.py` 中不存在的字段
- **修复**: 更新 `SkillRecord` 添加 `source_path`, `instance`, `diagnostics` 字段

### 2. Registry 方法缺失
- **问题**: `registry.py` 缺少 `unregister_hooks_for_skill`, `unregister_control_command`, `execute_control_command` 方法
- **修复**: 添加缺失方法

### 3. Hook 执行不支持异步
- **问题**: `execute_startup_hooks` 和 `execute_shutdown_hooks` 不支持异步回调
- **修复**: 添加 `asyncio.iscoroutinefunction` 检查，支持 async/await

### 4. 测试中的 SkillSource 枚举值错误
- **问题**: 测试中使用 `SkillSource.P_OOL`（下划线位置错误）
- **修复**: 改为 `SkillSource.POOL`

### 5. Windows 路径分隔符问题
- **问题**: 测试期望 POSIX 路径分隔符 `/`，Windows 使用 `\`
- **修复**: 使用 `os.path.normpath` 进行路径比较

### 6. import_from_hub 测试签名不匹配
- **问题**: 测试传递字典，但方法需要 `hub_url`, `skill_name`, `version` 参数
- **修复**: 更新测试使用正确签名
