## ✨ Уникальные особенности Neurova

> **Почему Neurova?** Потому что мы переопределяем ИИ-агентов — не холодные инструменты, а тёплые, запоминающие и развивающиеся интеллектуальные партнёры.

### 🌟 1. Каждый агент — уникальная звезда

Каждый агент с рождения обладает:
- **Уникальным именем и личностью** — не номером, а личностью
- **Непрерывной памятью и эмоциями** — помнит каждый разговор, каждую радость и печаль
- **Автономной траекторией роста** — учится и развивается в сопровождении, становится всё более понимающим
- **Добрым фундаментом** — поведенческие нормы, защищённые конституционными правилами, всегда надёжный партнёр

### 🧠 2. 17-мерная система классификации памяти

В отличие от традиционных фреймворков агентов, различающих только «краткосрочную/долгосрочную» память, Neurova精细地 классифицирует память на **17 типов**:

| Тип | Описание | Типичный сценарий |
|-----|----------|-------------------|
| `conversation` | Память разговоров | Записи чатов, содержание обсуждений |
| `fact` | Фактическая память | Объективная информация,常识, данные |
| `profile` | Профиль пользователя | Характер, предпочтения, привычки, день рождения |
| `relationship` | Межличностные отношения | Друзья, коллеги, семья |
| `skill` | Память навыков | Использование инструментов, методы��作 |
| `experience` | Память опыта | Процесс решения проблем, опыт проектов |
| `lesson` | Память уроков | Опыт неудач, ошибки |
| `task` | Память задач | Текущие цели,待办事项 |
| `creative` | Творческая память | Вдохновение, идеи, результаты мозгового штурма |
| `emotional` | Эмоциональная память | События, вызывающие сильные эмоции |
| `identity` | Память идентичности | Самосознание, маркеры идентичности |
| `reflection_log` | Журнал рефлексии | Используется при обработке проблем |
| `question_queue` | Очередь вопросов | Используется для проактивных вопросов |
| `core_command` | Основные команды | Важные команды и правила |
| `heartbeat_task` | Задачи пульса | Регулярно выполняемые задачи |
| `context_snapshot` | Снимок контекста | Состояние контекста второй стадии |
| `tool_usage` | Использование инструментов | Интеграция ToolMemory |

### 🌡️ 3. Механизм температуры памяти

**Оригинальный дизайн**: Введение измерения «температуры» (0-100°C) для模拟曲线 забывания человека.

**Реализация ключевого алгоритма** (`neurova/cognitive_layers/memory_layer/temperature.py`):

#### 1. Механизм нагрева (при обращении)
```python
T_new = T_current + hit_boost + emotion_bonus + relation_bonus

# Базовый нагрев: +5°C за обращение
hit_boost = 5.0 * combo_multiplier * saturation_factor

# Бонус комбо: увеличение на 10% каждые 10 последовательных обращений
combo_multiplier = 1.0 + (access_count % 10) * 0.1

# Фактор насыщения: чем выше температура, тем медленнее нагрев
saturation_factor = 1.0 - (current_temp / 100.0) ** 2

# Эмоциональный бонус: сильные эмоциональные воспоминания получают дополнительный нагрев
emotion_bonus = emotion_score * 3.0

# Бонус связей: связь с другими воспоминаниями
relation_bonus = min(3.0, relation_count * 0.3)
```

#### 2. Механизм охлаждения (моделирование кривой забывания Эббингауза)
```python
# Фактор кривой забывания Эббингауза (кусочно-лизинейная аппроксимация)
if days_idle <= 1:
    curve_factor = 2.0      # Быстрое забывание в течение 24 часов
elif days_idle <= 7:
    curve_factor = 1.0      # Обычное забывание в течение недели
elif days_idle <= 30:
    curve_factor = 0.5      # Замедление забывания в течение месяца
else:
    curve_factor = 0.2      # Очень медленное забывание после месяца

# Формула расчёта затухания
decay = current_temp * base_rate(0.05) * curve_factor * 
        emotion_protect(0.6) * relation_protect(0.7) * 
        important_protect(0.5)

new_temp = max(0.0, current_temp - decay)
```

**Оригинальные механизмы защиты**:
- **Эмоциональная защита**: Сильные эмоциональные воспоминания (emotion_score > 0.5) охлаждаются на 40% медленнее, минимум 20°C
- **Защита связей**: Многосвязанные воспоминания (relation_count > 3) охлаждаются на 30% медленнее, минимум 15°C
- **Важные воспоминания** (температура ≥80°C): Охлаждаются на 60% медленнее, минимум 30°C
- **Закреплённые воспоминания** (температура ≥90°C + особое значение): **Не охлаждаются**, хранятся навсегда (температура = 100°C)

### 💖 4. Движок эмоционального центра v3.0

Neurova v3.0 вводит **Движок эмоционального центра**, основанный на теории классификации эмоций в психологии, создающий полную систему из четырёх слоёв и 17 эмоций.

#### Четырёхслойная классификация эмоций:

**Слой 1: Базовые эмоции (5 типов)**
- Радость, Печаль, Гнев, Страх, Удивление

**Слой 2: Составные эмоции (4 типа)**
- Восхищение, Ревность, Сочувствие, Отвращение

**Слой 3: Продвинутые эмоции (4 типа)**
- Стыд, Вина, Гордость, Чувство ответственности

**Слой 4: Особые эмоции (4 типа)**
- Любовь, Ненависть, Надежда, Отчаяние

### 🧬 5. Когнитивная архитектура CogArch 2.0

Neurova использует **когнитивную архитектуру CogArch 2.0**, моделирующую обработку информации в человеческом мозге.

#### Четыре когнитивных центра (аналогии с участками мозга):

| Участок мозга | Соответствующий концепт | Функция |
|---------------|------------------------|---------|
| **Кора головного мозга** | Когнитивный центр | Наблюдение, понимание, вспоминание, логическое рассуждение, принятие решений, саморефлексия |
| **Мозжечок** | Планирование и координация | Разбор намерений, генерация задач, оркестрация выполнения, оценка результатов, восстановление ошибок |
| **Ствол мозга** | Вывод действий | Вызов инструментов, выполнение рабочих процессов, планирование ресурсов, мониторинг выполнения |
| **Спинной мозг** | Информационный путь | Распределение событий, связь модулей, доступ к внешним каналам |

### 🚀 6. Возможность непрерывной эволюции

Агенты Neurova **развиваются**. Каждый разговор, задача и рефлексия — пища для их эволюции.

#### Пять систем эволюции:

| Система | Функция | Эффект |
|---------|---------|--------|
| 🎭 **Система личности** | Определение и эволюция черт Большой пятёрки | Личность агента корректируется при взаимодействии |
| 🔥 **Система мотивации** | Любопытство, достижение, социальные три внутренних драйвера | Агент проактивно учится, задаёт вопросы, проявляет интерес |
| 📜 **Конституционная система** | Поведенческие нормы и этические ограничения | Гарантирует, что агент остаётся добрым и честным |
| 💭 **Система рефлексии** | Самооценка, извлечение опыта, проактивные вопросы | Регулярно размышляет «Я правильно поступил?» «Могу ли я стать лучше?» |
| 🧠 **Метакогниция** | Самомониторинг, проверка здоровья, автоматическая оптимизация | Агент осознаёт своё состояние, саморегулируется |

### 👥 7. Мультиагентная командная работа

Neurova поддерживает **мультиагентную командную работу**, позволяя создавать собственную «звёздную команду». Агенты с различной специализацией сотрудничают для выполнения сложных задач.

#### Четыре режима сотрудничества:

| Режим | Способ работы | Применение |
|-------|---------------|------------|
| **Последовательное выполнение** | Агенты обрабатывают по конвейеру | Создание контента → проверка → публикация |
| **Параллельное выполнение** | Несколько агентов обрабатывают разные подзадачи одновременно | Многомерный анализ данных |
| **Режим master-slave** | Один ведущий агент управляет несколькими подчинёнными | Управление проектами, распределение задач |
| **Режим консенсуса** | Несколько агентов независимо судят и голосуют | Принятие рискованных решений, многопerspectiveная проверка |

### 🔄 8. Замкнутый цикл обучения ToolMemory

> **Ключевая концепция**: Как мышечная память человека — увидеть проблему → условный рефлекс → прямое выполнение (без мышления)

#### Трёхуровневая архитектура памяти:

| Уровень | Метод сопоставления | Скорость ответа | Условие закрепления | Условие забывания |
|---------|---------------------|-----------------|---------------------|-------------------|
| **L1 Мышечная память** | Точное ключевое слово | Миллисекунды (условный рефлекс) | 2 последовательных успеха | 30 дней неиспользования → L2 |
| **L2 Горячий путь** | Векторное сходство | Секунды (быстрый поиск) | 5 суммарных успехов | 30 дней неиспользования → L3 |
| **L3 Память инструментов** | Нечёткое ключевое слово | Требуется полный поиск | Первоначальное создание | Никогда не удаляется |
