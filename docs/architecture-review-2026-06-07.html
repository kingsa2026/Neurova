Neurova 是一个基于 Python + Vue 3 的全栈 AI Agent 框架，核心理念是创建"有温度的智能体"。项目采用 FastAPI 后端 + Vue 3/TypeScript 前端架构，具备完整的认知层、执行层、工具层和接口层。

🏗️ 架构层次

认知层 (Cognitive Layer)

记忆系统（17种类型）、情感中枢引擎（四层17种情感）、元认知、知识图谱、模型适配器。这是系统的核心创新层。

执行层 (Execution Layer)

运行时抽象、传输层、执行监控、工作流引擎。支持本地执行和 Docker 容器化执行。

工具层 (Tool Layer)

MCP 客户端、工具编排、工具市场、工具路由。支持动态工具加载和沙箱执行。

接口层 (Interface Layer)

Vue 3 前端、77+ RESTful API、14 种通信渠道接入。提供完整的用户交互界面。

🔧 核心模块

Agent 核心 (agent_core.py)

Agent 主循环、聊天管线、Agent Loop 管理。采用深度模块化重构，从 2180 行优化到 1621 行。

记忆系统 (cognitive_layers/memory_layer/)

17 种记忆类型、温度机制、9 大认知机制、贝叶斯 EKI 优化器。支持多层隔离和跨 Agent 共享。

LLM 管理 (llm/)

多模型客户端、Provider 管理、多模态生成器。支持 OpenAI、Anthropic、Gemini 等多种模型。

渠道系统 (channels/)

飞书、钉钉、企业微信、Telegram、Discord 等 14 种通信渠道接入。支持 WebSocket 长连接和 Webhook 回调。

安全系统 (security/ + auth/)

JWT 认证、RBAC 授权、审计日志、三层安全防火墙。支持用户隔离和数据加密。

进化系统 (evolution/)

人格系统、动机系统、宪法系统、反思系统。支持 Agent 自主进化和能力扩展。
