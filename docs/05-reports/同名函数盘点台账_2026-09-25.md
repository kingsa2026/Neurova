## 2. 口径（单一事实源，脚本 `--help` 同文）

1. 扫描范围：`NeurUI/src`；
2. 文件：`.vue` / `.ts`，排除 `__tests__` 与 `*.test.ts` / `*.spec.ts`；
3. 定义形态：`function name(...)`、`const name = (...) =>`、`const name = async (...) =>`。
   参数表允许跨行，但形参表内不得出现 `{` `}` `;` —— 否则
   `const data = (res as any)?.data ?? res` 这类局部取值会被误判成函数定义；
4. 同名判定：按函数名聚合，且定义所在**文件数 ≥ 2**（同文件内重名不算跨文件平行定义）；
5. 同体判定：体文本去注释、去空白后**逐字相等**；
6. 局部耦合判据：体内出现页面 ref 解引用 `.value`、`props.`、`ref(`、`computed(`、
   i18n `t(`、`message.`、`route.`/`router.` 任一（均带词界，`split(` 不算），
   即判为耦合页面局部状态 —— 闭包捕获本组件作用域符号的「同名函数」不是可复用纯函数。

**同一个函数名可以同时落在 A/B 与 C。** 前例 `formatTime`（收口前实跑读数）：
全仓 22 处定义、12 种写法。其中 13 处构成 3 个跨文件同体组（应收口），
另 9 处各自成体（同名异体，必须保留差异）。若按「一个名字只能归一类」处理，
后者会被前者的同体组掩盖而整体消失 —— 那正是本次要消除的盲区。

复跑方式（读 HEAD 版本，非工作区）：

```bash
node /tmp/head-count.mjs formatTime   # 等价口径，按需重建
```

## 3. 三档定义与处置原则

- **A 档 · 同名同体 · 无局部耦合** —— 体逐字相同、不读页面局部状态与 i18n 文案。
  属真重复。**必须收口到单一属主**，否则两侧独立演进必然漂移。
  本档经本轮收口后应为**空**；非空即守卫判红。
- **B 档 · 同名同体 · 耦合局部状态** —— 体相同但读写本页 ref / 调本页编排函数
  （如 `openCreate` = `resetForm(); showModal.value = true`）。
  属**页面编排胶水**：合并只会造出「传一堆 ref 进去」的无谓间接层，
  不动它。登记不收口。
- **C 档 · 同名异体** —— 入参量纲、空值占位、i18n 依赖、数据来源不同。
  **禁止按名强行合并**：合并会改变其中一侧的既有显示，属表面抹除。
  逐组登记「机械判据」（可从体文本核实的事实），保留差异。

### 3.2 为什么 B 档不收口（并举证）

- `openCreate`（4 处）：体是 `resetForm(); showModal.value = true`，两个符号都是本页闭包。
  「抽成 `useCreateModal(resetForm, showModal)`」只是把 3 行换成 3 行加一层调用，
  且把两个 ref 的写权限外泄到共享模块。
- `releaseSrc`（4 处）：体是 `if (ownedUrl) { URL.revokeObjectURL(ownedUrl); ownedUrl = '' } src.value = ''`，
  `ownedUrl` 是面板私有 let、`src` 是私有 ref。已有 `dockPanels.revoke.test.ts` 锁住
  四块面板的 object URL 所有权语义；抽公共实现会把这些语义压成"传闭包进来"，
  守卫测试随之失去咬合力。
- `triggerUpload` / `triggerZipUpload`：体是 `fileInputRef.value?.click()`，
  一行且只碰本页 ref，合并只是改名。
- `fetchConflicts` / `handleResolveStrategy` / `strategyLabel`（睡眠设置页 vs 状态页）：
  读写本页 `conflicts` / `resolvingId` / `conflictApplyToStore` 并调本页提示与刷新编排。
  可收口的是它**下游**的数据层（`sleepApi.*` 已共享），页面编排层不必强行拉平。

### 3.3 为什么 C 档禁止按名合并（并举证）

- `formatDate`（4 种体）：`AgentFilePage` 收 ISO 串、`AgentMediaPage` 收 epoch 秒、
  `KnowledgePage` 收 ISO 串、`MetacognitionPage` 输出 `M/D`。按名合并会改掉其中至少两页的显示。
- `getFileIcon`（3 种体）：`utils/fileKind.ts` 返回 **UiIcon 名**（`fileText`），
  `FilePage` 返回 **emoji**（📄），`AgentFilePage` 也返回 emoji 但档位表不同
  （img/video/audio/pdf/text/json/xml/zip）。三份的**输出值域**不同，不是同一契约。
- `formatTime` 余下 16 处：`HealthPage` 空值显 `'N/A'`、`WorkflowVersionsDrawer` 显 `'-'`、
  `LogPage` 显空串；`ComputerUsePanel` 只输出时分秒；`CanvasDesignerPage` 输出 `MM-DD HH:mm`；
  `GrowthPage` 按入参类型分支；`WorkflowPage` 带 try/catch 兜底。
- `formatSize`（2 种体）：`AgentFilePage` 到 GB、`AgentMediaPage` 到 MB。
- `deleteFile` / `downloadFile`（各 2 处）：`api/modules/files.ts` 是**请求层**，
  页面版带确认弹窗与提示编排 —— 同名不同层。
