## 1. 导航与权限重构（前端为主）

**现状**：`config/navigation.ts` TOP_NAV_CATEGORIES 已有分组机制（`modelTools` 组现含 models/tool-layers/sandbox 三项，即顶部二级菜单先例）；`config/modules.ts` USER_MODULES 含 `{ key: '/aigc' }`；用户组权限目录 = module key。

**改法**：
1. `navigation.ts`：`modelTools.items` 追加 5 项（文本/图片/音频/视频/创作专区 → `/aigc/text` 等），并从侧栏移除。
2. `modules.ts`：TOP_MODULES 追加 5 个 key；USER_MODULES 删除 `/aigc`。**兼容**：前端模块匹配逻辑加规则——旧 key `/aigc` 命中即视同允许 `/aigc/*` 全组（存量用户组勾选不迁移、不洗数据；后端 user_group_model 匹配语义不变）。
3. `router/index.ts`：`/aigc` 下 5 子路由 + Studio 二级路由；`/aigc` 重定向 `/aigc/text`；删除旧单页引用。
4. i18n：`nav.aigcText/aigcImage/aigcAudio/aigcVideo/aigcStudio` 5 键 × 11 语。

## 2. 页面拆分与四生成页

### 2.1 拆分方式

AIGCPage.vue 按 Tab 边界拆为 5 个 page 组件（`pages/aigc/` 目录），公共部分抽 composable：
- `useCapModels`（能力感知模型下拉，现逻辑迁入）
- `useGenerationRuns`（结果区+记录列表+未决轮询，现 history tab 逻辑扩展为各页共享侧栏）
- 现有 `AIGCPage.*.test.ts` 5 个测试文件同步迁移拆分。


**逐页对齐点**

| 页面 | 表单 | 后端映射（现有端点） | 需后端新增/调整 |
|---|---|---|---|
| 文本生成 | prompt/model(auto)/temperature/max_tokens/会话连续 | POST /generation/text | 无（保持） |
| 图片生成 | prompt、**negative_prompt**、**画幅 chips**、参考图上传(→i2i)、风格模板 chips、模型(auto)、**张数**、**seed** | POST /generation/image | ImageGenerationRequest 已支持 negative/ref_images/num_images；**seed 字段补**；strength(低/中/高→0.35/0.65/0.9) 传 OPENAI edits/DASHSCOPE（protocols 已支持 refs） |
| 音频生成 | 文本、音色下拉（真实 VoiceEngine 音色列表，非硬编码 alloy）、语速 | POST /generation/audio | **音色列表端点** `GET /generation/voices`（现下拉是写死 OpenAI 音色名，与本地 TTS 引擎不符——对齐 pf1「工具页参数真实化」） |
| 视频生成 | **两段式（pf1 t2v 语义）**：脚本 → 先出静帧（scene-gen/protocols image）→ 静帧作首帧 i2v（ref_images）→ 轮询；协议/服务商/时长/分辨率已有 | /generation/image + /generation/video + /video/status | 前端编排即可，后端零改动（protocols i2v 首帧已实测） |
| （图片页 v2v） | pf1 `v2v/ecom` 标注 soon | — | 表单置灰 + soon 徽标，协议接入缓后台账 |

统一收口：四页共用「结果 + 本次会话历史 + 记录侧栏（账本 source 徽标）」面板组件 `AigcRunPanel.vue`（图/音/视产物预览 + 下载 + 失败原因，复用 withFileToken）。

### 3.2 数据模型（SQLite 新域 `aigc_studio`）

### 3.5 与画布引擎的关系（不重复建设）

创作专区是**向导式产品面**（普通创作者），NeurFlow 画布是**节点式专家面**；两者共享同一批底座：LLM 走 chat 路由、图像/视频走 protocols/runtime、TTS/字幕/合成复用 drama_nodes 内已实现的执行器函数（storyboard LLM 分镜、voice-over、subtitle、compose 三态）——`aigc_studio` 与 `drama_nodes` 共同 import `llm/generators/runtime.py` 单源，账本/恢复/鉴权全复用。画布侧「一键成片模板」保留为 power-user 入口。

## 4. 后端小改清单（四生成页配套）

1. `ImageGenerationRequest` 增 `seed: Optional[int]`、`strength: Optional[float]`，**按服务商能力自适应路由（用户决策 2026-09-14）**：
   - protocols 各协议按真实能力透传——ARK Seedream 支持 `seed`+`size`+`image`（strength 不支持）；DASHSCOPE `parameters.size/negative_prompt`（seed 视模型）；OPENAI_COMPAT 仅 `size/n`（seed/strength 多数兼容网关无效）。
   - 实现：`generate_image(creds, ..., seed=None, strength=None)` 逐协议组装 body，凡被丢弃的参数记入返回 `ignored_params: [...]`；
   - 端点把 `ignored_params` 写入任务账本 metadata，`/tasks` 透出，前端历史条目显示「当前服务商忽略：strength」徽标——**诚实可见，不静默丢弃**（对齐修复教义）。
2. 新增 `GET /generation/voices`（VoiceEngine/TTSManager 真实音色列表，替换前端硬编码 alloy）。
3. `TaskRecord` 增 `batch_key`/`project_id`（Studio 批量关联；账本默认路径已绝对化）。
4. `/generation/files` 无改动（Studio 产物同目录同鉴权）。

## 7. 风险与缓后

0. **节奏（已拍板）**：R1→R6 全量连续推进，不分两期；seed/strength 采用服务商能力自适应路由（§4.1）。
1. **尾帧/首尾帧生视频**：WAN/seedance 首帧已实测，尾帧（先画后动的插值）需临时上传/专用参数——Phase03 表单占位禁用，协议接入登记缓后。
2. **BGM 生成/音效**：字段保留（bgm_prompt/sound_effect），无生成协议——缓后。
3. **@角色一致性强度**：参考图注入实测取决于服务商（ARK image 字段/DASHSCOPE content 前置图），不做保证声明，UI 标「尽力一致」。
4. **视频合并中文字幕烧录**：依赖系统字体（pf1 教训 wqy-zenhei）——SRT 外挂 + 烧录失败诚实降级。
5. i18n 60+ 键 × 11 语的翻译质量（脚本生成+人工抽检 zh/en/ja）。
6. Studio 大文件（多集 × 多镜产物）retention：并入既有 `data/generations` 清理策略议题（缓后）。
7. R3-R5 体量大于既往任何单批，若需缩短战线可按 R1+R2 →（评审）→ R3-R5 分两期。
