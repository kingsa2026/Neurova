## A. 功能/端口缺口

### A1 Studio 尾帧（首尾帧插值）全链路 — P1 open

- **现状**：后端通道 L5 已通（`protocols.submit_video(last_frame=)`：Seedance role=`last_frame`、VEO `instance.lastFrame`；REST `/generation/video` 已有 `last_frame` 字段；facade `keyframe_to_video` 已转真实通道）。**Studio 侧三层未接**：
  - `aigc_studio/store.py` storyboards 表仅 `first_frame_path`，无 `end_frame_path` 列；
  - `aigc_studio/services.py.generate_shot_videos` 提交时不传尾帧；
  - 前端 `StudioProjectPage.vue` Phase03 卡无尾帧绘制/上传入口（火宝该功能为「先画后动」核心卖点）。
- **方案**：SQLite `ALTER TABLE storyboards ADD COLUMN end_frame_path`（沿用 store 启动幂等迁移模式，try-except duplicate 防御）→ services 提交 `last_frame=row["end_frame_path"]` 且 protocol 白名单外记 ignored → 镜头卡加「绘尾帧」（复用 retry image 通道，prompt 注入「结尾画面」语义）+ 上传替换 → 协议选 seedance 才启用尾帧槽（wan 显示能力不支持提示，对齐 R2 能力路由呈现）。
- **验收**：pytest（迁移幂等 / services 透传 / ignored 标注）+ 页面测试（seedance 显示尾帧槽、wan 隐藏）+ Live：真实服务商跑一条首尾帧镜头成片。
- **工作量**：后端 0.5d，前端 0.5-1d。**前置**：无（通道已就绪）。

### A2 WAN 本地参考媒体百炼临时上传 — P1 open

- **现状**：`protocols.submit_video` WAN 分支对非 http 参考媒体直接 `raise ValueError("…需经百炼临时上传（暂未实现）…")`（protocols.py:~526）。影响：Studio 逐镜首帧图（本地落盘产物）→ **wan 系视频必失败**，只能选 Seedance/VEO；REST 生成页同理（批次 R4 视频两段式在 wan 下首帧不可用）。这是当前 Studio 批量 i2v 的**主路径断点**。
- **方案**：实现 DashScope 文件上传 API（`POST /api/v1/uploads` 或百炼 `getPolicy` 直传 OSS，响应 `oss://` URL + 请求头 `X-DashScope-OssResourceResolve: enable`——该头 `_dashscope_image_generate` 已在发）。封装 `dashscope_upload_file(creds, local_path) -> "oss://…"` 进 runtime 单源；submit_video WAN 分支本地路径自动走上传；上传失败诚实报错不降级假提交。
- **验收**：协议单测（mock 上传链，本地路径→oss:// 引用 + 头携带）；Live 需真实百炼 Key 跑一条 wan i2v。
- **工作量**：1d（含上传 API 文档核对）。**风险**：百炼上传端点以官方文档实测为准，禁止虚构（教义）。

### A3 BGM / 音效生成通道 — P3 open

- **现状**：数据链全备（`storyboards.bgm_prompt`、`sound_effect` 列；`break_storyboards` 已抽取入库；导出 UI 无消费）；**无任何生成服务商通道**（huobao 实际也只出提示词）。
- **方案（分层）**：第一档=manifest 携带 bgm_prompt 供用户自行配乐（零成本，可并入 A5 一起做）；第二档=接 Fun Music / 天谱乐等（需服务商与计费决策，随 B1 一并拍）。当前登记为「提示词交付」即诚实，不假装有音频。
- **验收**：第一档仅 manifest 字段透出 + 前端导出面板展示提示词；第二档需产品选型后另立方案。
- **工作量**：一档 0.5d；二档待定。

### A4 video_to_video 实测协议 — P3 open

- **现状**：`runtime._UNSUPPORTED_TYPES = ("video_to_video",)` 诚实报错；`/generation` 无 v2v 端点；huobao 的 v2v 依赖 Kling 等**未验目录**（批次0 已删）。
- **方案**：候选实测序：① 百炼 wan2.x 视频重绘（若官方文档确认端点）→ ② 可灵 v2v（需 Key 与计费）→ ③ ComfyUI 自建通道（项目已有 comfyui_client）。协议进 `VideoProtocol` 枚举 + 端点 `/generation/video/v2v` + Studio 镜卡入口，三处同批次。
- **验收**：任一服务商真实端到端跑通一条 + 回归 ledger/recovery/鉴权链。**工作量**：1-2d/服务商。**前置**：可用 Key。

### A5 FFmpeg 字幕烧录 — P2 open

- **现状**：`services.merge_episode` 已生成 SRT（`build_srt` → `persist_bytes` → `episode.subtitle_path`），但 concat 命令**未烧录**（无 `-vf subtitles=`），成片无字幕；huobao 逐镜头带字幕处理。
- **方案**：concat 完成后追加第二步 `ffmpeg -i out.mp4 -vf subtitles=<srt_path> -c:a copy out_sub.mp4`（失败回退无字幕成片 + warning 字段，不中断）；路径含中文与 Windows 引号转义需按 ffmpeg subtitles filter 规则（`force_style` 可选默认样式）。
- **验收**：pytest 假 subprocess 断言命令序 + Live：自动下载件（批次5）真烧一条含中文 SRT。
- **工作量**：0.5d。**前置**：**Linux/桌面字体**（pf1 教训：无中文字体→方框；检测 `fc-list :lang=zh`，缺省回退外挂 SRT 不烧录并 warning 标注原因——诚实降级）。

### A6 Harmony 端 AIGC 页真实 API — P2 open

- **现状**：`NeurovaHarmony/entry/src/main/ets/pages/AIGCPage.ets` 全 mock（文件头与 :28 均 TODO M5）；Web 端 R1-R6 契约（五页 + studio）无对应。
- **方案**：对齐 Web 契约做 ArkTS 移植：`api.aigc.list/create/tasks/voices/usage` + studio 只读项目列表（编辑走 Web）。分两期：M5a 四生成页 + 记录；M5b studio 浏览/导出播放。
- **验收**：Harmony 侧契约测试（ets 无 vitest，按现有 mock 契约注释 + 真机冒烟）。**工作量**：2-3d。**前置**：Harmony 构建线排期。

## B. 产品/商务决策（需拍板）

### B1 按量计费钱包 — decision

- **现状**：L4 已把**计量**做齐（`aigc_gen_usage`：按用户/类型/模型/时长）；token 侧 usage_accounting 已有；缺**定价表与余额/扣费/充值**（printfilm services/billing 对标：上游成本×倍率、易支付回调）。
- **决策点**：是否面向多租户收费。若做：定价维度（张/秒/字符）+ 钱包域（余额、流水、幂等扣费、失败冲正）+ 支付通道，独立方案文档，预估 5-8d。计量数据已备好不浪费。
- **验收/前置**：产品定倍率与支付通道后启动。

### B2 开放 API Key 面 — decision

- **现状**：全部 AIGC 端点只吃 JWT（Bearer + access_token 回退）；printfilm 有 `X-Api-Key` 第三方调用面 + 配额。Neurova 已有 MCP server 外表面（mcp_server_api）部分覆盖此需求。
- **决策点**：是否开放给外部系统集成。若做：api_keys 表（哈希存储，对齐 API key 外置加密现状）、作用域权限（只 /generation/* 或含 studio）、限流与配额（L4 计量可直接复用）。预估 2-3d。
- **验收**：跨进程 key 调用端到端 + 密钥静态扫描（对齐 S-04 审计基线）。

### B3 服务商一键配置引导 — decision

- **现状**：providers.json 手工配置 + ModelPage 管理；huobao「一个 Key 写入文本/图像/视频三项推荐配置」降低首配门槛。
- **方案**：ModelPage 加「快速配置」：选服务商 → 一次写 3 类默认模型 + 自动能力探测（detect-capabilities 现成）+ 三端连通性测试。**量级** 1d。**触发**：新用户首配投诉率数据或产品要求。
