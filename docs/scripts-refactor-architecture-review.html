Neurova 安装/启动脚本重构架构审查

基于深度模块原则和TDD方法的脚本重构方案

生成时间: 2026-06-08 09:09

当前问题分析

代码重复问题

  • Colors 类在 install.py 和 start.py 中重复
  • ProgressBar 类在 install.py 中定义，其他脚本无法使用
  • print_logo() 函数在三个脚本中重复实现
  • _supports_color() 函数在三个脚本中重复实现
  • 端口检查逻辑在 start_oneclick.py 和 check_and_start.py 中不同

架构问题

  • Windows-only 代码（PowerShell、netstat、taskkill）
  • 端口检测方法不一致（PowerShell vs socket vs netstat）
  • 缺少统一配置管理（端口、路径硬编码）
  • 缺少错误处理标准化
  • 缺少日志记录标准化
  • 缺少测试覆盖

重构方案

1. 创建共享工具模块

  • scripts/common.py - 统一颜色、Logo、进度条
  • scripts/config.py - 统一配置管理
  • scripts/port_utils.py - 跨平台端口工具
  • scripts/health_check.py - 统一健康检查

2. 脚本合并与重构

  • 合并 start.py、start_oneclick.py、check_and_start.py
  • 创建统一的 start.py 支持多种模式
  • 添加跨平台支持（Windows/Linux/Mac）
  • 添加 install.sh 支持 Linux/Mac
