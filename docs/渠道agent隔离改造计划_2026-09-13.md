## Neurova 落地映射（保持现有全局 ChannelManager 骨架，语义对齐）

| QwenPaw | Neurova 落地 |

| channels 段进 agent.json | `data/channel_configs.json` 升 v2：`{version:2, agents:{agent_id:{channel_type:cfg}}}`；旧顶层格式首载迁移进 `default`（幂等） |

| conflict-check 配置级跨 agent 身份比对 | PUT 保存前：遍历所有 agent 配置的同平台+跨平台身份字段（app_id/bot_token/corpid…），撞身份 → 409 |
