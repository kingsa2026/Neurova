## ✨ ميزات Neurova الفريدة

> **لماذا Neurova؟** لأننا نعيد تعريف وكلاء الذكاء الاصطناعي - ليست أدوات باردة، بل شركاء ذكاء اصطناعي دافئين يتذكرون وينمون.

### 🌟 1. كل وكيل هو نجمة فريدة

كل وكيل يولد بـ:
- **اسم وشخصية فريدة** - ليس رقمًا، بل كيانًا ذو شخصية
- **ذاكرة وعاطفة مستمرة** - يتذكر كل محادثة، كل فرح وحزن
- **مسار نمو ذاتي** - يتعلم وينمو في الرفيق، يصبح أكثر فهمًا
- **أصل طيب** - إرشادات سلوكية محمية بقواعد دستورية، شريك موثوق دائمًا

---

### 🧠 2. نظام تصنيف الذاكرة 17 الأبعاد

على عكس أطر عمل الوكيل التقليدية التي تميز فقط بين الذاكرة "قصيرة المدى/طويلة المدى"، يقوم Neurova بتصنيف الذاكرة بدقة إلى **17 نوعًا**:

| النوع | الوصف | السيناريو النموذجي |
|-------|-------|-------------------|
| `conversation` | ذاكرة المحادثات | سجلات الدردشة، محتوى النقاش |
| `fact` | ذاكرة الحقائق | المعلومات الموضوعية، المعرفة العامة، البيانات |
| `profile` | ملف المستخدم | الشخصية، التفضيلات، العادات، عيد الميلاد |
| `relationship` | العلاقات interpersonal | الأصدقاء، الزملاء، العائلة |
| `skill` | ذاكرة المهارات | استخدام الأدوات، طرق التشغيل |
| `experience` | ذاكرة الخبرات | عملية حل المشكلات، خبرة المشاريع |
| `lesson` | ذاكرة الدروس | خبرات الفشل، الأخطاء |
| `task` | ذاكرة المهام | الأهداف الجارية، قائمة المهام |
| `creative` | ذاكرة إبداعية | الإلهام، الأفكار، نتائج العصف الذهني |
| `emotional` | ذاكرة عاطفية | الأحداث التي تثير عواقب قوية |
| `identity` | ذاكرة الهوية | الإدراك الذاتي، علامات الهوية |
| `reflection_log` | سجل التأمل | تُستخدم عند معالجة المشاكل |
| `question_queue` | طابور الأسئلة | تُستخدم للأسئلة الاستباقية |
| `core_command` | الأوامر الأساسية | الأوامر والقواعد المهمة |
| `heartbeat_task` | مهام نبض القلب | المهام المنفذة بانتظام |
| `context_snapshot` | لقطة السياق | حالة سياق المرحلة الثانية |
| `tool_usage` | استخدام الأدوات | تكامل ToolMemory |

### 🌡️ 3. آلية درجة حرارة الذاكرة

**تصميم أصلي**: إدخال بُعد "درجة الحرارة" (0-100 درجة مئوية) لمحاكاة منحنى النسيان البشري.

**تنفيذ الخوارزمية الأساسية** (`neurova/cognitive_layers/memory_layer/temperature.py`):

#### 1. آلية التسخين (عند الوصول)
```python
T_new = T_current + hit_boost + emotion_bonus + relation_bonus

# التسخين الأساسي: +5 درجة لكل وصول
hit_boost = 5.0 * combo_multiplier * saturation_factor

# مكافأة الكومبو: زيادة 10% كل 10 وصلات متتالية
combo_multiplier = 1.0 + (access_count % 10) * 0.1

# عامل التشبع: كلما ارتفعت درجة الحرارة， قل التسخين
saturation_factor = 1.0 - (current_temp / 100.0) ** 2

# مكافأة العاطفة: الذاكرة العاطفية القوية تحصل على تسخين إضافي
emotion_bonus = emotion_score * 3.0

# مكافأة العلاقة: الارتباط بالذكريات الأخرى
relation_bonus = min(3.0, relation_count * 0.3)
```

#### 2. آلية التبريد (محاكاة منحنى نسيان إيبينغهاوس)
```python
# عامل منحنى نسيان إيبينغهاوس (تقريب قطعي)
if days_idle <= 1:
    curve_factor = 2.0      # نسيان سريع خلال 24 ساعة
elif days_idle <= 7:
    curve_factor = 1.0      # نسيان عادي خلال أسبوع
elif days_idle <= 30:
    curve_factor = 0.5      # تباطؤ النسيان خلال شهر
else:
    curve_factor = 0.2      # نسيان بطيء جدًا بعد شهر

# حساب التلاشي
decay = current_temp * base_rate(0.05) * curve_factor * 
        emotion_protect(0.6) * relation_protect(0.7) * 
        important_protect(0.5)

new_temp = max(0.0, current_temp - decay)
```

**آليات الحماية الأصلية**:
- **الحماية العاطفية**: الذاكرة العاطفية القوية (emotion_score > 0.5) تبرد بنسبة 40% أبطأ، الحد الأدنى 20 درجة
- **حماية العلاقة**: الذاكرة متعددة الارتباطات (relation_count > 3) تبرد بنسبة 30% أبطأ، الحد الأدنى 15 درجة
- **الذكريات المهمة** (درجة الحرارة ≥80): تبرد بنسبة 60% أبطأ، الحد الأدنى 30 درجة
- **الذكريات المثبتة** (درجة الحرارة ≥90 + أهمية خاصة): **لا تبرد أبدًا**، تخزين دائم (درجة الحرارة = 100)

يستخدم Neurova **بنية الإدراك CogArch 2.0**، لمحاكاة معالجة المعلومات في الدماغ البشري.

#### أربعة مراكز إدراكية (تشبيهات مناطق الدماغ):

| منطقة الدماغ | المفهوم المقابل | الوظيفة |
|--------------|----------------|---------|
| **قشرة الدماغ** | المركز الإدراكي | المراقبة والفهم، تذكر المعلومة، الاستنتاج المنطقي، اتخاذ القرار، التأمل الذاتي |
| **المخيخ** | التخطيط والتنسيق | ت分解 النية، توليد المهام، تنسيق التنفيذ، تقييم النتائج، استرداد الأخطاء |
| **جذع الدماغ** | الإخراج الحركي | استدعاء الأدوات، تنفيذ سير العمل، جدولة الموارد، مراقبة التنفيذ |
| **الحبل الشوكي** | مسار المعلومات | توزيع الأحداث، اتصال الوحدات، الوصول إلى القنوات الخارجية |

### 🚀 6. قدرة التطور المستمر

وكلاء Neurova **ينمون**. كل محادثة ومهام وتأمل هي غذاء لتطورهم.

#### خمس أنظمة تطور:

| النظام | الوظيفة | التأثير |
|--------|---------|---------|
| 🎭 **نظام الشخصية** | تعريف وتطور سمات الشخصية الكبيرة الخمس | شخصية الوكيل تتكيف مع التفاعل |
| 🔥 **نظام الدافع** | الفضول، الإنجاز، الاجتماعية - ثلاث دوافع داخلية | الوكيل يتعلم ويسأل ويهتم بشكل استباقي |
| 📜 **النظام الدستوري** | الإرشادات السلوكية والقيود الأخلاقية | يضمن أن الوكيل يظل طيبًا وصادقًا |
| 💭 **نظام التأمل** | التقييم الذاتي، استخراج الخبرة، الأسئلة الاستباقية | يتأمل بانتظام "هل فعلت الصواب؟" "هل يمكنني أن أكون أفضل؟" |
| 🧠 **المeta-إدراك** | المراقبة الذاتية، فحص الصحة، التحسين التلقائي | الوكيل يدرك حالته ويتحكم في ذاته |

### 👥 7. التعاون الجماعي متعدد الوكلاء

يدعم Neurova **التعاون الجماعي متعدد الوكلاء**، مما يسمح لك بإنشاء "فريق نجومك". يتعاون وكلاء ذوو تخصصات مختلفة لإنجاز المهام المعقدة.

#### أربعة أوضاع تعاون:

| الوضع | طريقة العمل | سيناريو التطبيق |
|-------|-------------|----------------|
| **التنفيذ المتسلسل** | الوكلاء يعالجون بالتناوب | إنشاء المحتوى → مراجعة → نشر |
| **التنفيذ المتوازي** | عدة وكلاء يعالجون مهام فرعية مختلفة في نفس الوقت | تحليل بيانات متعددة الأبعاد |
| **وضع الأسيطيل-الم.master** | وكيل رئسي واحد يأمر عدة وكلاء فرعيين | إدارة المشاريع، تكليف المهام وتلخيصها |
| **وضع الإجماع** | عدة وكلاء يحكمون بشكل مستقل ثم يصوتون | اتخاذ القرارات المحفوفة بالمخاطر، التحقق متعدد وجهات النظر |

### 🔄 8. التعلم المغلق الحلقة ToolMemory

> **المفهوم الأساسي**: مثل الذاكرة العضلية البشرية - رؤية المشكلة → انعكاس شرطي → تنفيذ مباشر (بدون تفكير)

#### بنية الذاكرة ثلاثية المستويات:

| المستوى | طريقة المطابقة | سرعة الاستجابة | شرط التثبيت | شرط النسيان |
|---------|---------------|----------------|-------------|-------------|
| **L1 الذاكرة العضلية** | مطابقة الكلمات المفتاحية الدقيقة | ميلي ثانية (انعكاس شرطي) | نجاحان متتاليان | 30 يومًا دون استخدام → L2 |
| **L2 المسار الساخن** | مطابقة التشابه المتجهي | ثوانٍ (بحث سريع) | 5 نجاحات متراكمة | 30 يومًا دون استخدام → L3 |
| **L3 ذاكرة الأدوات** | مطابقة الكلمات المفتاحية الضبابية | يتطلب بثًا كاملاً | الإنشاء الأولي | لا تُحذف أبدًا |

## حزمة التقنيات

### الخلفية
- **Python 3.10+**
- **FastAPI** - إطار عمل API

- **Console**: React 18 + TypeScript + Vite
- **NeuUI**: React 18 + TypeScript + Vite + Zustand + Ant Design 5
