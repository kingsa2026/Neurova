## 一、引言

本应用由 Neurova 团队开发，致力于保护用户隐私。本政策说明我们如何收集、使用、存储、共享与保护您的个人信息。

## 二、我们收集的信息

### 2.1 您主动提供的信息

- **账号信息**：登录时输入的用户名/邮箱、密码（加密存储）
- **智能体配置**：您创建的智能体名称、描述、人格设定
- **对话内容**：您与智能体的聊天消息（流式传输）
- **记忆条目**：您主动添加或智能体生成的记忆
- **知识库内容**：您上传的文档与元数据

### 2.2 自动收集的信息

- **设备信息**：设备型号、操作系统版本（HarmonyOS 6.1+）
- **网络信息**：网络类型（WiFi/蜂窝）、连接状态
- **使用日志**：应用崩溃日志、性能指标（不含个人内容）

### 2.3 权限使用说明

本应用声明的全部权限及其用途如下，权限清单与 `entry/src/main/module.json5` 中的 `requestPermissions` 完全一致：

| 权限 | 用途 | 使用时机 |
|------|------|----------|
| `ohos.permission.INTERNET` | 与您配置的后端 API、WebSocket 服务通信 | 始终（应用运行时） |
| `ohos.permission.GET_NETWORK_INFO` | 检测网络连接状态以决定是否重连 WebSocket | 始终（应用运行时） |
| `ohos.permission.CAMERA` | 扫描二维码以完成设备与账号的扫码配对 | 仅在使用扫码配对功能时 |

## 三、信息使用

我们仅将收集的信息用于以下目的：

1. **提供核心服务**：登录认证、智能体对话、记忆管理、知识库检索
2. **改善产品体验**：基于崩溃日志与性能指标优化应用
3. **安全保障**：异常检测、防止滥用与未授权访问

我们**不会**将您的信息用于：
- 向第三方出售或出租
- 跨应用追踪您的行为
- 与广告网络共享

## 四、信息存储与安全

### 4.1 存储位置

- **本地存储**：登录令牌（access_token）、应用配置、侧边栏状态使用 `@ohos.data.preferences` 加密存储
- **服务器存储**：智能体数据、对话历史、记忆、知识库存储于您在应用内配置的后端服务器（连接地址由用户自行配置，生产环境强制使用 HTTPS/WSS）

### 4.2 安全措施

- 所有网络通信通过 HTTPS/WSS 加密传输（生产环境强制）
- 密码使用 bcrypt 哈希存储，永不以明文形式保留
- 登录令牌使用 JWT 标准，含过期时间
- 服务器数据库受 `threading.RLock` 保护，避免并发损坏

### 4.3 数据保留

- **账号数据**：账号删除后立即清除
- **对话历史**：保留至用户主动删除
- **记忆数据**：保留至用户主动删除
- **日志数据**：保留 30 天后自动清理

## 五、信息共享与第三方 SDK

我们**不会**与任何第三方共享您的个人信息，但以下例外：

1. **法律法规要求**：应有权机关合法要求
2. **用户明确同意**：您主动同意共享的场景
3. **服务提供商**：仅委托处理必要数据（如云服务商），并签署保密协议

### 5.1 第三方 SDK 与系统能力披露

本应用使用以下第三方组件与系统能力，相关数据均在本地处理，不上传至任何第三方服务器：

| 类型 | 名称 | 用途 | 数据处理 |
|------|------|------|----------|
| 测试框架 | Hypium（@ohos/hypium） | 仅在测试构建中集成，发布版本不含 | 无数据收集 |
| 系统能力 | `@ohos.net.connection` | 网络状态监测（配合 GET_NETWORK_INFO 权限） | 仅本地读取网络类型 |
| 系统能力 | `@ohos.multimedia.camera` | 扫码配对功能调用相机 | 不保存图像，仅实时识别二维码 |
| 系统能力 | `@ohos.data.preferences` | 本地加密存储登录令牌与配置 | 仅本地存储，加密后写入 |
| 系统能力 | `@ohos.web.webview` | 隐私政策展示页 | 不收集浏览数据 |

本应用**不集成**任何广告 SDK、推送 SDK、统计分析 SDK 或跨应用追踪 SDK。

## 六、您的权利

您对个人信息享有以下权利：

- **访问权**：查看您的账号数据、对话历史、记忆内容
- **更正权**：修改错误的个人信息
- **删除权**：删除账号、对话、记忆或知识库条目
- **导出权**：以 JSON 格式导出您的全部数据
- **撤回同意权**：随时撤回对权限的授权（系统设置 → 应用管理 → Neurova）

## 七、未成年人保护

本应用不面向 18 岁以下未成年人。我们不会故意收集未成年人的个人信息。若发现未经监护人同意的未成年人注册，我们将主动删除相关账号。

## 八、隐私政策变更

我们可能不时更新本政策。重大变更时将通过应用内通知告知您。继续使用本应用即视为同意更新后的政策。
