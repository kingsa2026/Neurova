# KingPolo 品牌指南

## 🎨 品牌识别

### 官方名称

**英文**: KingPolo

**发音**: /kɪŋ pəˈloʊ/ (King-Po-Lo)

### 品牌定位

> **智能协作，王者风范**

KingPolo 是一个功能强大、设计优雅的智能体代理框架，专为多 Agent 协作而生。

## 📖 名称含义

### King (王者)
- **领导力**: 在智能体框架领域的领先地位
- **卓越品质**: 提供最高标准的性能和可靠性
- **掌控全局**: 强大的多 Agent 协调能力

### Polo (波罗)
- **连接**: 象征智能体之间的协作网络
- **流动**: 信息和消息的高效传递
- **完整**: 球形网络，无所不包

### 金波罗 (中文)
- **金**: 珍贵、高质量、可靠
- **波**: 波动、传播、信息流动
- **罗**: 罗网、网络、协作系统
