## 1. 功能简介

心流知识库是 Neurova 的核心扩展模块，为您的 AI 助手提供以下能力：

| 能力 | 说明 |
|------|------|
| 🔌 **外部知识接入** | 连接心流知识库，管理海量文档 |
| 🔍 **语义检索** | 基于向量搜索的智能语义匹配 |
| 🔗 **记忆同步** | 知识库与记忆系统双向联动 |
| 🧬 **认知进化** | 自动发现知识盲点，主动学习成长 |
| 🤖 **RAG 增强** | 为 Agent 提供知识增强的上下文 |

## 2. 快速开始

### 2.1 前置条件

1. ✅ 拥有心流知识库账号
2. ✅ 已获取心流平台 API Key
3. ✅ Neurova 服务已正常运行

### 2.2 快速流程

```
Step 1: 配置 API Key
   └── POST /v1/knowledge/configs

Step 2: 创建知识库
   └── POST /v1/knowledge/collections

Step 3: 上传文档
   └── POST /v1/knowledge/documents/upload

Step 4: 开始检索
   └── POST /v1/knowledge/search

Step 5: 开启 RAG 增强
   └── POST /v1/knowledge/rag
```

### 2.3 完整示例

```typescript
import {
  createKnowledgeConfig,
  createCollection,
  uploadDocument,
  searchKnowledge,
  ragRetrieve,
} from '@/api/modules/knowledge'

// 1. 配置 API Key
const config = await createKnowledgeConfig({
  source_type: 'iflow',
  api_key: 'your_iflow_api_key',
  config_name: '我的知识库'
})

// 2. 创建知识库
const kb = await createCollection({
  name: 'Python 学习库',
  description: '收藏的 Python 教程和文档'
})

// 3. 上传文档
const file = event.target.files[0]
await uploadDocument(kb.id, file, (e) => {
  console.log(`上传进度: ${e.progress}%`)
})

// 4. 语义检索
const results = await searchKnowledge({
  query: '如何理解 Python 装饰器',
  collection_id: kb.id
})
console.log(results)

// 5. RAG 增强检索（自动同步到记忆）
const context = await ragRetrieve({
  query: '装饰器是什么',
  user_id: currentUser.id,
  sync_to_memory: true
})
```

## 3. API Key 配置

### 3.1 为什么需要配置 API Key？

心流知识库的 API Key 由用户自行管理，每个用户使用自己的心流账号。

```
用户 A ──► API Key A ──► 知识库 A
用户 B ──► API Key B ──► 知识库 B
```

### 3.2 配置接口

**创建配置**

```http
POST /v1/knowledge/configs
Content-Type: application/json
Authorization: Bearer <your_jwt_token>

{
  "source_type": "iflow",
  "api_key": "your_iflow_api_key",
  "config_name": "工作知识库",
  "base_url": "https://platform.iflow.cn"  // 可选
}
```

**参数说明**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| source_type | string | ✅ | 知识源类型，固定为 `iflow` |
| api_key | string | ✅ | 心流平台 API Key |
| config_name | string | ❌ | 配置名称，便于识别 |
| base_url | string | ❌ | 心流 API 地址，默认使用官方地址 |

**响应示例**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": "cfg_abc123",
    "source_type": "iflow",
    "name": "工作知识库",
    "is_active": true,
    "created_at": "2025-05-14T10:00:00Z"
  }
}
```

### 3.3 查看/更新/删除配置

```http
# 查看配置列表
GET /v1/knowledge/configs

# 查看单个配置
GET /v1/knowledge/configs/{id}

# 更新配置
PUT /v1/knowledge/configs/{id}
{
  "api_key": "new_api_key",
  "config_name": "新名称"
}

# 删除配置
DELETE /v1/knowledge/configs/{id}
```

### 3.4 注意事项

⚠️ **安全提示**：
- API Key 仅在创建和更新时返回，之后不会明文显示
- 请妥善保管您的 API Key，不要泄露给他人
- 每个用户的配置完全隔离，不可查看他人配置

## 7. 记忆同步

### 7.1 双向同步机制

```
┌─────────────────────────────────────────────────────────────┐
│                      记忆 ↔ 知识库 双向同步                    │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│   【知识 → 记忆】                                             │
│   当你检索知识时，相关内容会自动同步到记忆系统                  │
│   • 建立知识-记忆关联                                         │
│   • 更新记忆访问频率                                         │
│   • 标记知识来源                                              │
│                                                              │
│   【记忆 → 知识库】                                           │
│   当某段记忆被频繁访问，可以同步到知识库保存                    │
│   • 高频记忆自动推荐                                          │
│   • 用户手动触发同步                                          │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 7.2 同步知识到记忆

```http
POST /v1/knowledge/memory/sync
{
  "knowledge_item_ids": ["item_001", "item_002"],
  "link_type": "from",           // 关联类型
  "bidirectional": true          // 双向关联
}
```

**关联类型说明**

| 类型 | 说明 |
|------|------|
| `derived` | 知识由记忆衍生 |
| `from` | 知识来源自记忆 |
| `explains` | 知识解释记忆 |
| `supports` | 知识支持记忆 |
| `contradicts` | 知识与记忆矛盾 |

### 7.3 同步记忆到知识库

```http
POST /v1/knowledge/memory/sync-to-kb
{
  "memory_ids": ["mem_001", "mem_002"],
  "collection_id": "kb_xyz789",
  "title": "从记忆同步"  // 可选
}
```

### 7.4 查看关联

```http
GET /v1/knowledge/memory/links
GET /v1/knowledge/memory/links?memory_id=mem_001
GET /v1/knowledge/memory/links?knowledge_id=item_001
```

│   ┌─────────┐     ┌─────────┐                                   │
│   │ 知识库  │────►│  检索   │◄── 你的问题                         │
│   │  检索   │     │         │                                   │
│   └─────────┘     └────┬────┘                                   │
│                        │                                         │
│       ┌────────────────┼────────────────┐                       │
│       ▼                ▼                ▼                       │
│  ┌─────────┐     ┌─────────┐     ┌─────────┐                    │
│  │  记忆   │────►│  合并   │────►│  生成   │                    │
│  │  检索   │     │  上下文 │     │  回答   │                    │

## 10. 用户隔离说明

### 10.1 隔离机制

所有知识库数据均按用户隔离，确保数据安全：

```
┌─────────────────────────────────────────────────────────────────┐
│                       JWT Token 解析                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   Token Payload:                                                │
│   {                                                             │
│     "user_id": "user_123",     ← 用于数据隔离                   │
│     "neuser_id": "neu_456",    ← 多用户管理标识                 │
│     "username": "zhangsan"                                    │
│   }                                                            │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 10.2 隔离范围

| 数据类型 | 隔离方式 |
|----------|----------|
| API Key 配置 | 按 `user_id` 隔离 |
| 知识库 | 按 `user_id` 隔离 |
| 文档 | 按 `user_id` + 知识库隔离 |
| 记忆关联 | 按 `user_id` 隔离 |
| 进化进度 | 按 `user_id` 隔离 |

### 10.3 安全保证

✅ **数据隔离**：用户只能访问自己的数据
✅ **配置独立**：每个用户使用自己的 API Key
✅ **Token 验证**：所有请求必须携带有效 JWT Token
✅ **API Key 安全**：API Key 存储时加密，仅创建者可见

## 11. 常见问题

### Q1: 如何获取心流知识库 API Key？

1. 登录心流平台 (https://platform.iflow.cn)
2. 进入「开发者中心」→「API Key 管理」
3. 创建新的 API Key
4. 复制 Key 并在 Neurova 中配置

### Q2: 上传文档后多久可以检索？

通常需要 1-2 分钟完成索引建立。文档状态变为 `indexed` 后即可检索。

### Q3: 记忆同步会影响性能吗？

不会。同步操作在后台异步执行，不阻塞主流程。

### Q4: 如何删除已同步的数据？

- **删除记忆关联**：`DELETE /v1/knowledge/memory/links`
- **删除知识条目**：在知识库管理中删除对应文档
- **清除所有同步数据**：删除知识库配置

### Q5: RAG 检索返回空结果怎么办？

1. 检查知识库中是否有相关文档
2. 尝试使用更通用的搜索词
3. 检查 API Key 配置是否正确
