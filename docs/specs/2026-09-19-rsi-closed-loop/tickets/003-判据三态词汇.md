# 003 · 判据三态词汇与共享表达

**Blocked by**: 002

## 目标

让"证据缺失"在 RSI 判据里成为一个**可传递、可显示、不可被当作通过**的显式状态，
供 004-009 共用同一词汇而不是六处各写一套。

## 三态定义（spec §2 已定）

| 态 | 含义 | 允许的后果 |
|---|---|---|
| `passed` | 有证据且判据满足 | 可晋升 / 可停 |
| `failed` | 有证据且判据不满足 | 不晋升，继续观察 |
| `unevidenced` | 取不到判据所需数据 | **绝不**按 passed 处理；必须出现在观测面 |

附加状态 `measurement_blind`：`unevidenced` 的一种特例，专指
"评测用例因参数回退到 setpoint 而失去区分力"（由 007 产生，008/009 消费）。

## 现状（必须被这套词汇取代的写法）

- `orchestrator.py:176-184` 空回滚历史返回 `0.0` —— 把"没有证据"编码成"证据为 0 天"。
- `orchestrator.py:262` `float((convergence.get("metrics") or {}).get("roi", 0.0) or 0.0)`
  —— 缺键兜底成 0，使 `roi<0` 守卫永不触发（`convergence_analyzer.py:131-135` 从不产出 roi 键）。
- `eval_harness.py:32-39` `_param()` 取不到参数回退 setpoint 且不计入分母差异 —— 满分假象。
- `deployment_controller.py:106` `metrics.get("days_without_rollback", 0)` —— 同上。

## 交付内容

1. `GateVerdict`：字段 `state`（三态枚举）+ `reason` + `evidence`（可为 None），
   `__bool__` 只在 `passed` 为真 —— 从类型上阻止 `if verdict:` 把 unevidenced 当通过。
2. 用 `GateVerdict` 重写 `evaluate_phase_transition` 的返回契约（内部判定，外部旧 bool 语义经
   `__bool__` 保持兼容，避免本单爆炸半径扩大）。
3. CONTEXT.md 记 `可证伪 / unevidenced / measurement_blind` 三个术语与不可混用约定
   （spec §7 末段）。

**实现期自纠两处**
1. 初版把 `passed`/`unevidenced` 同时写成类方法和实例属性 —— Python 里同类中不能共存，
   改为只保留工厂，判定统一走 `bool(v)` 与 `v.state`，避免两套语义互相遮蔽。
2. 新写的 `test_missing_evidence_is_unevidenced_not_passed` 起初要求 phase 0 也列出
   `days_without_rollback` 缺项 —— 而 phase 0 门槛是 0 天，门槛为零时缺读数不构成未知，
   断言写错了预期。已改并注明 phase 1 的同类断言在 `test_gate_verdict.py`。

**本单改变了红灯基线 A 的解锁条件（重要）**
把 `insufficient_data` 判为 `unevidenced` 之后，phase 0→1 也不再自动放行：
实测基线 A 的失败信息由 `phase=1` 变为 `phase=0`。
即**晋升链现在需要 004（回滚天数）+ 006（真 roi）+ 007/008（真收敛态）同时到位**才可能转绿，
只修 004 不够。这是"可证伪"决策的必然结果，也说明原先 0→1 的自动推进本身就是无据放行。
依赖图已在 `000-索引.md` 同步。
