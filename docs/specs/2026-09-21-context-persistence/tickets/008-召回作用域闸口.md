# 008 召回作用域闸口

**Blocked by**: 002

## 目标

持久层是**第二条读路径**，现状完全不过隔离闸口。本片让它与视图路径同源。

## 现状（实测，基线脚本 §8）

- 群聊归档（`session_id=project_roomB`、`chat_scope=room:project_roomB`）落库后：
  - 单聊池（`session_id=s_direct`）召回 **0 条**（拿 session 做精确等值过滤 → 恒空）；
  - 无会话池（`session_id=None`）召回 **1 条**，**无任何闸口** → 房间内容可见。
- `evicted_chunks` 只存 `metadata` 字符串，读侧构造 `ContextInput` 时**不解析**它
  → 即使放行，闸口也无据可判。
