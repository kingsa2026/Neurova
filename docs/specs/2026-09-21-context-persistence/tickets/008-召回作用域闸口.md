# 008 召回作用域闸口

**Blocked by**: 002

## 目标

持久层是**第二条读路径**，现状完全不过隔离闸口。本片让它与视图路径同源。

## 现状（实测，基线脚本 §8）

- 群聊归档（`session_id=project_roomB`、`chat_scope=room:project_roomB`）落库后：
  - 单聊池（`session_id=s_direct`）召回 **0 条**（拿 session 做精确等值过滤 → 恒空）；
  - 无会话池（`session_id=None`）召回 **1 条**，**无任何闸口** → 房间内容可见。
- `evicted_chunks` 只存 `metadata` 字符串，读侧构造 `ContextInput` 时**不解析**它
  → 即使放行，闸口也无据可判。

## 涉及层

- [x] 数据层：`chat_scope` 落库（002 的 v1 列）。
- [x] 逻辑层：`recall_evicted` 的 session 过滤从"精确等值"改为
      **"session 优先 + 跨 session 兜底"**（D1 要跨重启跨会话可取），
      然后过作用域闸口。
- [x] 逻辑层：作用域判定**复用** `collaboration/memory_scope.py` 的
      `filter_by_scope` / `scope_from_metadata`——**不新写第二份规则与阈值**。
- [x] 逻辑层：库里 `chat_scope` 缺失时按 `session_id` 的 `project_` 前缀回溯
      （与既有 `scope_from_metadata` 同规则）。
- [x] 测试：`tests/unit/context/test_ledger_recall_scope_gate.py`
- [x] live-verify：`tests/manual/context_ledger_recall_scope_90.py`

## 验收标准

- **A8**：群聊归档在单聊轮召回**不可见**；跨房间互不可见；群轮可见 direct + 本群。
- 无会话池（`session_id=None`）不再泄露房间内容。
- 与视图路径的判据同源：断言两处调用同一个 `filter_by_scope`（不复制规则）。
- 双源去重不破：同内容在内存台账与持久台账各有一份时只出一条。

## 不做

- 不做 `draw` 侧的作用域改造（B2 已完成）。

## 实施结果

- 红灯 → 绿灯：`pytest tests/unit/context/test_ledger_recall_scope_gate.py -q` 改前
  `4 failed, 3 passed` → 改后 `7 passed`。红灯三条直接对应规格 D13 的实测：
  无会话池看到房间内容（`['单聊归档…', '群聊归档…']`）、群轮看不到 direct、
  内存台账里的房间内容未被拦、召回路径没调 `filter_by_scope`。
- 根因：`recall_evicted` 把可见性交给 "`session_id` 精确等值"——单聊池恒空（查不到），
  无会话池（`session_id=None`）全放行。**可见性不是 session 等值问题，是作用域问题**。
- 改法：新增 `ContextPool._allowedRecallItems()`，闸口落在**两条源合并之后**
  （只挡持久源等于半个闸口）；判据调 `collaboration.memory_scope.filter_by_scope`，
  本群/本房间取 `self.turn_scope`（写入侧打标与读侧放行同一个值，不存在错配）。
  持久源查询的 `session_id` 参数改为 `None`（不再精确等值），可见性全交闸口判定。
- 既有消费方同步：`test_context_ledger_migration.py` 的两条"归档事实读得回来"用例
  原先靠 session 等值取得可见性，按新契约改为在**同一房间轮次**内召回——判据语义
  随契约更新，**断言未删**（仍锁条数与内容与 `chat_scope`）。
- live-verify（真库 + **真跨进程** + 真闸口探针）：`PYTHONPATH=. python
  tests/manual/context_ledger_recall_scope_90.py` —— 单聊轮与无会话池均只见 direct
  （含另一进程同库开池），群 B 轮见 direct + 本群，他群互不可见，
  探针实测召回路径调用 `filter_by_scope` 1 次（`collab=false`）。
- 回归 A/B：`tests/unit/context` + `tests/context` + `test_context_eviction_index.py`
  失败集合改前改后**逐行相同**（4 条 `context_pool_bugfix` 顺序断言，与本片无关）；
  `tests/unit/collaboration` + 相邻 8 个套件 593 passed。
- 净 LOC：生产代码 +50 / −8（负向来自 session 精确等值参数与旧注释的删除）。
