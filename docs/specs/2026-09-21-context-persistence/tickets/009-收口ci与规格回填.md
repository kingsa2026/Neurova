# 009 收口：CI 登记与规格回填

**Blocked by**: 001-008

## 目标

把本批的判据钉进常驻门禁，并把实施期对规格的偏离如实回填。

## 涉及层

- [ ] 新用例逐文件单跑全绿后登记 `scripts/ci/protected_tests.txt`。
      红灯文件在转绿前**不得**登记（AGENTS.md 修复教义第 3 条）。
- [ ] 规格回填：`2026-09-21-context-persistence-design.md` §2 各决定条目补"偏离记录"，
      §8 未决事项按实施结论收口（U1–U4）。
- [ ] 取证脚本登记：`tests/manual/context_persistence_baseline_90.py` 的读数与
      实施后读数对照（写放大、命中率、迁移耗时、启动代价），差异逐条说明。
- [ ] 台账：`docs/05-reports/上下文三链路修复台账_2026-09-21.md` 的 B4 行状态更新。
- [ ] A/B 自证：涉及共享文件时按 `CONTRIBUTING.md` 做 stash A/B，失败集合逐行比对。

## 验收标准

- `protected_tests.txt` 全量复跑通过；新增项逐文件单跑全绿。
- 规格状态从"待实施"改为"已实施"并附实测读数（不写未验证的结论）。
- 未做到的地方显式写明（如真机长跑未走查），不以"测试全绿"代替。

## 不做

- 不做 B5（规模：嵌入落库 + 批量打分）、B6（清死线）——各自独立立项。
