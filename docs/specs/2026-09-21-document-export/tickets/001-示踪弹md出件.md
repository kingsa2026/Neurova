# 001 示踪弹：Markdown 出一页真 PDF

**Blocked by**: 无

## 目标
agent 调 `write_pdf(content="# 标题\n\n正文")` 就能在 `data/generations/` 拿到一份
合法 PDF，响应带 `download_url`。这条切片的价值是"端到端通了"，覆盖面刻意窄。

## 涉及层
- [ ] 预重构：`requirements.txt` 加 `reportlab>=4.0` 并装进 `.venv`；把
      `neurova/core/ffmpeg.py:198 _cjk_font_candidates()` 的中文字体探测提为公开的
      `find_cjk_font()`，`has_cjk_font()` 改为复用它（烧录与 PDF 共用一个口径）
- [ ] 数据层：`neurova/document_model.py` — 中间文档树数据类（heading / paragraph /
      list / table / image / page_break）与归一化，纯函数，不 import reportlab
- [ ] 逻辑层：`neurova/document_sources.py::parse_markdown` — 首批只支持
      `#`~`######`、段落、`-`/`1.` 列表、`**粗**`、`*斜*`、`` `行内码` ``
- [ ] 渲染层：`neurova/document_pdf.py::render_document` — 树 → flowables → 字节，
      返回 `pages` 与 `font{mode,name}`；**本文件是唯一 import reportlab 处**
- [ ] 工具层：`tool_executor._execute_write_pdf` — `content`/`content_html` 二选一
      校验（同给或都不给 → 结构化错误，不猜优先级）；缺省落
      `data/generations/<slug>-<hash8>.pdf`，文件名必须过
      `api/endpoints/generation.py:738` 白名单；返回
      `{file_name, file_path, download_url, bytes, pages, font, warnings}`
- [ ] 注册：`builtin_tools.py` schema、`tool_executor` 分派表、
      `skills/permissions.py:31` 归 `file` 单类（多归属在 003）
- [ ] 降级：显式 `font` > 探测到的 CJK TTF（真嵌入）> `STSong-Light` CID；
      走 CID 时 `warnings` 必须带"未嵌字体，阅读器缺 CJK 会方框"
- [ ] reportlab 缺席：返回结构化错误并写明缺包，服务启动与其它工具不受影响
- [ ] 测试：`tests/unit/document/`（sources/model 纯函数）、`tests/unit/tools/test_write_pdf.py`（端到端）

## 验收标准
- 新增用例先红后绿，且红灯原因是"工具不存在/出不了件"，不是导入错误
- 出件经 pypdf 读回 `pages >= 1`；以嵌入字体路径渲染时中文正文可抽回原文
- 无中文字体环境（CI 即此态）断言 `font.mode == "cid"` 且 `warnings` 非空，
  **不断言中文可抽取**
- 空输入/纯空白输入 → `error`，不产出空白 PDF
- 缺省文件名满足 `^[A-Za-z0-9._-]+$`；中文标题不参与文件名
- `test_builtin_tools_expansion.py` 的"`_BUILTIN_SCHEMAS ⊆ 分派表`"不变量仍绿
- 单独检出 HEAD 能跑通本工单全部用例（新模块与测试同批入库，不留未跟踪依赖）
