# 000 索引 — 文档导出子系统（write_pdf）

规格源：`docs/specs/2026-09-21-document-export-design.md`（决定 D1-D6、契约、子集边界均以它为准）。
本目录是它的工单化拆分，8 张，每张是一颗可独立验证的示踪弹。

| # | 标题 | Blocked by | 完成后可验证 |
|---|---|---|---|
| 001 | 示踪弹：Markdown 出一页真 PDF | 无 | agent 调 `write_pdf` 得到 generations 里的 PDF 与 `download_url` |
| 002 | 表格与跨页表头 | 001 | 含 GFM 表格的多页文档表格不断行、表头重复 |
| 003 | 图片内嵌与权限多归属 | 001 | 本地/远程图进 PDF，超限与失败都可见；工具同时受 file 与 network 归类约束 |
| 004 | HTML 子集入口 | 001、002、003 | `content_html` 与 `content` 出同一棵树、同一渲染出口 |
| 005 | 模板预设与逐次覆盖 | 001 | 三套模板 + 页眉/页脚/页码/边距覆盖可分辨 |
| 006 | path 分支与工作区锚定 | 001 | 给定 `path` 落在工作区且 `..` 被拒 |
| 007 | 前端 PDF 被动预览 | 001 | 产物卡点开 PDF 在 dock 内显示，可下载 |
| 008 | 收口：CI 登记与规格回填 | 001-007 | 新用例全绿并进 `protected_tests.txt`，spec 状态更新 |

## 与 spec §9 的两处偏差（有意为之）

1. **权限多归属并入 003**，不再排在第 7 位。理由：`write_pdf` 第一次触碰网络出口就是
   远程图那一刻，把"归类"放到能力之后会留一段"工具在权限面上不认识自己"的窗口。
2. 腾出的位置给 **008 收口片**（CI 登记、全量回归、spec 状态回填）。理由：本仓的红线是
   "逐文件单跑全绿才登记子集"，这件事需要所有切片就位后一次做，不能提前。
