# 003 图片内嵌与权限多归属

**Blocked by**: 001

## 目标
`![alt](本地路径|generations 文件名|http(s))` 真进 PDF；同时把 `write_pdf` 的权限归类
改成可多归属，让"会出网的文件工具"在权限面上被如实表达。

## 涉及层
- [ ] 逻辑层：图片来源解析三路 —— 工作区相对/绝对路径（复用 `_workspace_base` 与
      `_path_within`）、`data/generations` 内文件名、http(s) 经
      `neurova/llm/generators/runtime.py:205 persist_media`（其出网 SSRF 校验已在）
- [ ] 渲染层：reportlab `Image`，按页宽等比缩放；上限 20 张、单图 20 MB，超限跳过
      并 `warnings`；读图失败降级为 alt 文本 + `warnings`
- [ ] 权限层：`skills/permissions.py` 的 `_TOOL_TO_CATEGORY` 当前由 dict 推导生成，
      一工具进两个集合会**静默被后者覆盖**——改为多值映射并保留旧读法兼容，
      同时加不变量测试：`write_pdf` 必须同时在 `file` 与 `network` 下可见
- [ ] 测试：`tests/unit/document/`、`tests/unit/tools/test_write_pdf.py`、
      `tests/unit/skills/test_skill_permissions.py`

## 验收标准
- 本地小图（PNG）内嵌后 pypdf 读回页面图像对象计数 ≥ 1
- 远程图走 `persist_media`：断言经该函数（monkeypatch 计次），不在别处新开下载路径
- 第 21 张图被跳过且 `warnings` 点名，不抛错
- 不存在的本地路径 → alt 文本降级 + warning，PDF 仍出件
- 权限回归：把 `write_pdf` 从任一类别移除，不变量测试必须红
- 越权防护不变：`file.read_only=True` 的技能仍拿不到 `write_pdf`
