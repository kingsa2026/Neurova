# 002 表格与跨页表头

**Blocked by**: 001

## 目标
同一份 Markdown 里的 GFM 管道表格变成真表格，跨页时表头重复，宽表不溢出页面。

## 涉及层
- [ ] 数据层：`document_model` 补 table 节点（表头行 + 数据行 + 列对齐）
- [ ] 逻辑层：`document_sources.parse_markdown` 识别 `|a|b|` 与 `|---|:--:|` 对齐行
- [ ] 渲染层：`document_pdf` 用 `Table(repeatRows=1)`；列宽按内容自适应，超页宽时
      缩字号一次，仍超则截断单元格内容并计入 `warnings`（不溢出、不静默）
- [ ] 测试：`tests/unit/document/test_document_pdf.py`

## 验收标准
- 一个跨 2 页的长表格，pypdf 读回两页都含表头文字
- 6 列超宽表不抛错，`warnings` 点名被截断的列
- 表格语法残缺（缺对齐行 / 列数不齐）→ 按段落渲染 + warning，不出半张表
- 001 的既有用例全绿（不得回归出件主路径）
