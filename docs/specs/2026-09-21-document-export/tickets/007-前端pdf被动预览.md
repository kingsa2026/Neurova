# 007 前端 PDF 被动预览

**Blocked by**: 001

## 目标
聊天产物卡里点开一个 PDF，在右侧 dock 内用浏览器原生查看器显示，并能下载。
今天的现实是：PDF 掉进 `text` 面板按文本渲染二进制。

## 涉及层
- [ ] 类型：`NeurUI/src/stores/rightDock.ts:19` 的 `DockTabKind` 加 `'pdf'`
- [ ] 分派（两份表同批，注释已互指）：`NeurUI/src/utils/artifacts.ts:19` 与
      `neurova/api/endpoints/artifacts_api.py:44` 各加 `pdf`；`DOCK_ICONS` 加 pdf 图标
- [ ] 面板：新建 `NeurUI/src/components/chat/dock/panels/PdfPreviewPanel.vue`，
      `<embed :src="withFileToken(url)">` + 标题栏 + 下载按钮 + 可见错误态
- [ ] 挂载：`RightDock.vue:18-26` 分发链加一行
- [ ] 测试：`NeurUI/src/components/__tests__/`（与既有面板测试同目录）、
      `src/stores/__tests__/rightDock.test.ts` 若断言 kind 全集则同步
- [ ] i18n：优先复用既有 `dock.download`、`chat.artifactUnavailable`；新增键必须
      11 份 locale 同批（`locale-consistency.test.ts` 会红）

## 验收标准
- `vue-tsc --noEmit` 绿；vitest 新用例绿
- 后端 `_KIND_BY_EXT` 与前端 `KIND_BY_EXT` 对 `.pdf` 给出同一个 kind（加一条跨端一致性断言）
- URL 经 `genFiles.ts:11 withFileToken()`，不带 token 的请求不作为通过依据
- 下载失败进入可见错误态，**不得**照抄 `ImagePreviewPanel.vue:95-102` 的 `catch {}`
- 手工验证：起前端 + 后端，用 001 产出的 PDF 走一遍点开与下载（浏览器可达则截图为证；
  不可达要在交付说明里写明未做视觉验证）
