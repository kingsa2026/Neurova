# 005 模板预设与逐次覆盖

**Blocked by**: 001

## 目标
三套内置模板（`blank` / `report` / `cover`）产出肉眼可辨的差异，且逐次参数能盖过预设。

## 涉及层
- [ ] 数据层：`document_model.DocSettings`（template、header_text、footer_text、
      page_number、margin_mm，默认 `report`/18mm/页码开）
- [ ] 渲染层：reportlab `onPage` 回调画页眉/页脚/`第 N 页`；`cover` 首页只放标题与日期
- [ ] 优先级：显式参数 > 模板预设 > 内置默认（本仓已有同款口径，见 D2 取舍）
- [ ] 测试：`tests/unit/document/test_document_pdf.py`

## 验收标准
- 同一内容三种 template 产出的字节不同，且页数/首段位置可分辨
- `blank` 下 pypdf 抽回文本不含页眉标题；`report` 下含
- `footer_text=""` 显式传空视为"关掉页脚"，不回落成预设
- 边距改变后页面可容纳的每行字符数变化（用长行断言），证明 margin 真生效
