# 020 本体注册表与五条入库校验（G08）

**Blocked by**: 019
**阶段**: E4（§6.1–6.2）

## 目标
概念/关系类型成为可声明的数据，脏事实进不了底座。

## 涉及层
- [ ] 数据层：`ontology_terms`（kind、parent、domain、range、cardinality、disjoint_with、required_props、version）
- [ ] 逻辑层：`ontology/term_registry.py` 的 `OntologyTermRegistry` + `ontology/validation.py` 的
      `OntologyValidationReport` 五条（域值域 / 基数 / 父子一致性 / 不相交 / 必填）
- [ ] 接线：`admit()` 段3 前半；违规产可定位 `fact_id` 的报告，不吞错
- [ ] 测试：`tests/unit/knowledge/ontology/test_term_registry.py`、`test_validation_five_rules.py`

## 验收标准
- 新增一个类型不需要改任何 `.py`（用一个纯数据用例证明）。
- 违反值域或基数的写入被拒且报告可定位。
