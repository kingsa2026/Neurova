# 013 图检索器入链（灭 B04）

**Blocked by**: 011
**阶段**: E2（§7）

## 目标
26% 覆盖率的图结构在答题时被真正利用：多跳查询能作为一等检索器进链。

## 涉及层
- [ ] 逻辑层：图投影的多跳查询走 SQLite 递归 CTE（`knowledge_subjects` + `knowledge_facts`），
      不依赖 `manager.py` 的 Python 侧 BFS 作为权威读面
- [ ] 装配：注册 `GraphRetriever` 进 `MemoryRetrievalChain`，遵守 ADR 0005 的 `add_retriever` 单点纪律
      （雷区：`chat_pipeline.py:220-276`）
- [ ] 测试：`tests/integration/test_graph_retriever_in_chain.py`

## 验收标准
- 构造一个 2 跳事实链，对话检索能带出终点事实。
- 检索链装配数、优先级序有测试固化，防回填。
- 关闸后与 011 的开闸态一致（每项新增都可独立关闭）。
