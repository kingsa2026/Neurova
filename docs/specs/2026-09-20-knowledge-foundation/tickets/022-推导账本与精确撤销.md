# 022 推导账本与精确撤销

**Blocked by**: 021
**阶段**: E4

## 目标
规则修订或前提撤销时，受影响的推导事实能被精确定位并撤销，不牵连原始事实。

## 涉及层
- [ ] 数据层：`knowledge_derivation_edges`、`ontology_rule_fires`
- [ ] 逻辑层：`ontology/derivation_ledger.py` 的 `DerivationLedger`（按规则版本/前提集撤销）
- [ ] 读侧：检索结果区分原始与推导事实，推导项带 `derived_from`
- [ ] 测试：`tests/unit/knowledge/ontology/test_derivation_retract.py`

## 验收标准
- 撤销一条前提 ⇒ 仅依赖它的推导事实消失，其余仍在。
- 推导事实永不作为原始事实呈现（读侧可断言）。
