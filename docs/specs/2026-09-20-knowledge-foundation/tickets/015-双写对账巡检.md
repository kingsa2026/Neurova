# 015 双写对账巡检（E1 出口判据）

**Blocked by**: 009, 010
**阶段**: E1 收口（§9 E1 出口、R1）

## 目标
底座与旧四路对同一批真实数据的双写结果可自动对账，差异为 0 才允许进入 E2。

## 涉及层
- [ ] 逻辑层：`foundation/reconcile.py` 的 `FoundationReconciler`——按 `content_key`/`subject_key`
      对齐旧条目、图节点、TKG 事实与底座事实，产出差异分类报告
- [ ] 巡检：可被 `start.py --check` 或独立脚本调用，差异非零时退出码非 0
- [ ] 测试：`tests/integration/test_foundation_reconcile.py`

## 验收标准
- 对 §1.2 真实 130 条跑对账，输出可读差异清单；人为制造一处不一致时巡检必须失败。
- 差异清零后才允许合并 011。
