# 012 · 类型不丢、冲突不再"检测了但不拦"

**Blocked by**: 001

## 目标

两类静默失真同属"归档语义"：传进来的类型被吞成 SEMANTIC，冲突检测跑完什么都不改变。

## 涉及层

- [x] 数据层：`MemoryType`（`memory_layer/models.py:15-23`）补 `WORKFLOW_EXPERIENCE`
  （扩展式改动，先并存不动旧值）
- [x] 逻辑层：`manager.py:750-754` 的"非法类型 warning 后回落 SEMANTIC" ⇒
  未知类型显式拒绝或落 `unevidenced`，不得静默换类型
- [x] 逻辑层：冲突检测（`post_chat_pipeline.py:2217-2248`）现仅 `logger.warning` +
  StepResult，且执行时机在 `save_memory` **之后** ⇒ 二选一：前移到写入时并可否决，
  或在 StepResult 与文档里显式声明"纯观测、不阻断"
- [x] 测试：两条路径各一正一反

## 验收标准

- 传 `workflow_experience` ⇒ 落该类型且可按类型检索（当前必红：静默变 SEMANTIC）。
- 未知类型 ⇒ 明确失败或标无证据，且计数可见。
- 冲突场景 ⇒ 选"可否决"则断言第二条矛盾写入被拒；选"纯观测"则断言其明写不阻断
  （不许再留中间态）。

## 净 LOC

枚举扩展 +1；若选"纯观测"分支，预计净负（去掉误导性处置分支）。

## 执行结果（已完成）

- `MemoryType.WORKFLOW_EXPERIENCE = "workflow_experience"` 入枚举——写入方
  （`post_chat_pipeline._step_record_workflow_experience`）一直在传这个值，
  枚举缺项使每条工作流经验在 `remember()` 里被静默降级成 SEMANTIC。
  现在按声明类型落库、可按类型检索、跨重启保留。
- 未知类型不再静默换类型：回落 SEMANTIC 时把原声明留在
  `metadata["_declared_memory_type"]`，并计数进 `_stats["unknown_memory_type_count"]`
  （0 才是正常态）。按 D1 口径**行照存不砍量**——直接拒绝会把用户内容丢成一次 500。
- 冲突检测二选一裁决：**显式降级为纯观测**（票面待裁决 4 已定）。理由：本步跑在
  `save_memory` 之后，检测器只给矛盾分，判不出"两条里哪条为准"（回滚机制本身有
  Step 9.95 版本快照兜底，缺的是判据），据此否决会随机丢真实记忆。
  落地：StepResult `data["blocking"] = False`（有无冲突都写，口径一致）、
  message 明写"（纯观测，不阻断写入）"、docstring 记理由与升级前置条件；
  删掉"记忆冲突检测通过"这种读起来像已处置的表述。
- 同契约文字面命中点同步：`api/endpoints/memory/base.py:73` 与
  `crud.py:34` 的 memory_type 说明补 `workflow_experience`。
- 测试：`tests/unit/cognitive_layers/memory_layer/test_memory_type_semantics.py`
  （5 条：声明类型即落库类型 / 按类型检索只取到它 / 跨重启保留 / 未知类型留痕+计数 /
  未知类型仍保住行 / 合法类型不留痕）+
  `tests/unit/agent/test_conflict_detection_observation_only.py`
  （3 条：有冲突⇒`blocking=False`+message 明写+读到真实记忆且不回滚不新增 /
  无冲突同样声明 / docstring 自陈语义）。
- 登记给 015（前端处置面，同契约命中点）：`NeurUI/src/api/modules/memory.ts:9`
  的 `MemoryTypeValue` 联合类型、`MemoryPage.vue` 的类型页签/下拉/色板均尚无
  `workflow_experience`——工作流经验能在库里，却在界面上筛不出来。
- 净 LOC：生产 +18（枚举 +5、manager 留痕 +8、pipeline message/docstring +5，
  并删除"检测通过"的误导性表述）。
