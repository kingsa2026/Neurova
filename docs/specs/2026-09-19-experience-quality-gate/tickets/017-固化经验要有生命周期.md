# 017 · "通过门控"不等于"永久固化"

**Blocked by**: 002, 006

## 目标

斩断审计里最隐蔽的一条级联：门越好 ⇒ 越固化。成功率被写成温度，而温度高到某个值就
永久免衰减，且该类节点没有任何淘汰路径。

## 涉及层

- [x] 逻辑层：`pattern_crystallizer.py:287` `temperature = rate * 100` 与
  `memory_layer/temperature.py:291-297`「`>= 80` 不衰减」的叠加后果
- [x] 逻辑层：`MemoryType.PATTERN` 全仓仅 2 处引用（`auto_classifier.py:112`、
  `pattern_crystallizer.py:285`），无任何 decay/prune 分支作用其上 ⇒ 补淘汰/复核路径
- [x] 逻辑层：`temperature.py:284-289` 的 `is_crystallized` 豁免通道当前无人设置
  （结晶器构造节点未传该标志）⇒ 要么真用，要么删掉这条假豁免
- [x] 测试：单元 + 时间推进后的行为断言

## 验收标准

- 构造 `success_rate=1.0` 的结晶经验 ⇒ 时间推进或采纳后证据转差时必须可降权/淘汰
  （当前必红：一次好读数换来永久豁免）。
- 豁免只可作用于"多次采纳成功"或"人工升格"，不得作用于单次自述成功率。
- 反向锁：确被持续采纳且成功的高价值经验，衰减不得在 1 个周期内把它清零。

## 净 LOC

允许为正；删掉假豁免则部分抵负。

## 执行结果（已完成）

审计里最隐蔽的一条级联被拆成"入库封顶 + 真实衰减 + 读侧屏蔽"三段，缺一都不成闭环：

- **入库封顶（斩断"门越好⇒越固化"）**：`_store_candidate` 的
  `temperature = rate * 100` 改为 `rate * 75`。旧写法让 rate≥0.8 的节点直接落进
  温度策略的「`>= 80` 不衰减」豁免区——**一次自述好读数换来永久豁免**。
  现在满分 75 仍在衰减区内，排序信息不丢（高成功率仍更热，见
  `test_rate_still_orders_patterns`）。
- **豁免只剩一条正当来路**：管理页/API 的人工升格
  （`lifecycle_stage=crystallized` → `manager.py:1922` → `on_decay(is_crystallized=True)`）。
  这条通道**仍然存在且被测试钉住**（`test_is_crystallized_channel_remains_exempt`），
  防止后来者把"不许自述换豁免"误读成"删掉固化功能"。
  同时锁住"结晶入库不得自带 `is_crystallized` 标志"。
- **真实淘汰路径**：`PatternCrystallizer.reap_stale_patterns(idle_days=30, decay_step=15)`
  给闲置超期的 PATTERN 节点降温。此前 `CognitiveStorageEngine.update_temperature()`
  **全仓零调用方** ⇒ 审计说的"该类节点没有任何 decay/prune 分支"是准确的。
  巡检走新增的 `iter_nodes()`（只读列举）——**不能走 `retrieve()`**：006 让检索命中即
  `touch()` 并刷新 `updated_at`，用 retrieve 巡检等于"我来看了你一眼"就把闲置清零，
  闲置判定数学上永不成立（这条在实现中被测试抓到并改正）。
- **淘汰必须看得见**：`COLD_PATTERN_TEMPERATURE = 20.0` 冷档线，`retrieve()` 的过滤
  带上 `min_temperature`，`_apply_filters` 支持该键。只衰减不屏蔽是假淘汰——
  冷掉的条目照样进 prompt 就等于没淘汰。
- **写入方**：`post_chat_pipeline` 复盘通道每 50 轮调一次 `reap_stale_patterns()`
  （与结晶候选 LLM 裁决同一低频通道，不逐轮扫库）。
- **反向锁**：被持续取用的模式由 006 的检索记账（命中 +10 温度、刷新 `updated_at`）
  自动免于被扫，且升温能跑赢一个衰减周期
  （`test_retrieval_credit_outpaces_one_decay_cycle`、
  `test_recently_used_pattern_is_left_alone`）；冷档只作用于结晶模式，
  普通语义/情景记忆不受影响（`test_other_memory_types_are_not_touched`）。
- 测试：`tests/unit/evolution/experience/test_pattern_lifecycle.py`（6 条）+
  `tests/unit/evolution/experience/test_pattern_reaping.py`（7 条）。
- 净 LOC：生产 +52（`reap_stale_patterns` 27、`iter_nodes` 17、冷档过滤与常量 8）。
  本票的"删掉假豁免"一格核实为**不该删**：`is_crystallized` 通道有人设置
  （管理页/API 升格、`init_memories.py` 预置），结晶器不传它是正确的，
  票面把"结晶器未传"误判成"通道无人使用"。
