票面验收原文：「清单逐条有结论：**迁移 / 不迁移（写明风险与不修理由，回审计文档 §2
新开登记项）**，无一条含糊。」

> 事实源：`tests/unit/skills/test_skill_entry_choke_migration.py` 的 `ENTRY_LEDGER`
> 与 `tests/unit/tool_tools_*.py` 的守卫用例逐条比对命中行数。本文件是人类可读副本，
> 两者不一致即守卫判红。

## 清单一（命令重跑生成）

```bash
grep -rn "\.execute_skill(\|_execute_builtin_tool(\|get_tool_engine()\|tool_router\.execute(" \
  --include=*.py neurova/ | grep -v "src-tauri\|/tests/\|def execute"
```

## 处置结论

| 入口 | 结论 | 理由 / 不迁移的风险 |
|---|---|---|
| `neurova/tool_executor.py`（`execute_skill_tool`） | **即咽喉本体** | 唯一执行缝，其余入口都改指它 |
| `neurova/skill_system.py`（`SkillRegistry.execute_skill`） | **即被调层** | 注册表实现本体；另有两处回退（RuntimeManager 缺席 / 隔离执行异常）回到同一实现 |
| `neurova/tool_layers/tool_router.py` | **即咽喉内层** | `_execute_tool_core` 调它；路由器不是入口 |
| `neurova/agent/loops/base.py` | **已迁移**（003） | 原生链两条出口改走 `native_tool_dispatch.execute_native_tool` |
| `neurova/router.py` | **不迁移（降级分支）** | 只在 `agent.tool_executor` 缺席时可达；真机恒不走到。迁进来会把独立注册表台架（评测/脚本）拖进治理面 |
| `neurova/api/endpoints/skill.py` | **不迁移（降级分支）** | 同上：无 Agent/执行器时的评测台架路径 |
| `neurova/skills/executor.py` | **非调用点** | `SkillExecutor` 协议 docstring 里的方法名 |
| `collaborate/workflow/scheduler.py` | **已迁移** | 改走 `executor.execute_skill_tool`；轮级上下文跨事件循环可见性有用例钉住 |
| `collaboration/neurflow/adapters.py`、`node_registry.py` | **已迁移** | 原先 `get_tool_engine` 是**不存在的导入**（静默零同步），改指 `api/endpoints/tool_layers.get_tool_engine` |
| `api/endpoints/tool_layers.py`（`/tools/execute`） | **已迁移** | 有 agent 时走 `agent.tool_executor.execute`（经票据/钩子/治理）；无 agent 的评测路径保留引擎直调（反向锁钉住） |
| `tool_layers/tool_orchestrator.py` | **对照组，零变化** | 本就经 `executor.execute`，登记为对照防误改 |
