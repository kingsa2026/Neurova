# 009 · 经验要带得出度量：置信度、耗时与结构身份落库

**Blocked by**: 004

## 目标

让 `confidence_score` / `execution_time` 两列在**生产写侧**真的有值，
并让经验条目携带可复用的**结构身份**（工具序列 + 参数形状指纹），
使"这条经验值多少"与"这串工具该怎么传参"第一次成为可查询的事实。审计 L-08 / L-09。

## 现状（真实库实测，全程 `mode=ro`）

- `experience_records` 103 行：`confidence_score` nonNULL **0/103**、`execution_time` nonNULL **0/103** ——
  写侧 `post_chat_pipeline.py:1657-1674` 根本不传这两颗 kwarg。
- 全仓唯一写入口是手工端点 `api/endpoints/experience_knowledge_api.py:179` 的
  `confidence_score = 1.0 if exp.success else 0.0` —— 正是上一批工单 015 在行契约里明令禁止的二值兜底
  （同文件 106-110 注释："不再回落成 1.0/0.0"）。
- `context` 只存 `{"user_input": …}` ⇒ `find_similar_experiences` 的
  `0.6*keyword + 0.3*topic`（`experience_knowledge_base.py:680`）里 topic 档恒 0、relevance 上限 0.6；
  等效门槛是 2-gram 重叠率 ≥25%，随机跨句 60 组配对仅 10 组可召回。
- `ExperienceRecord`（`skills/models.py:355-360`）无参数字段 ⇒ 召回的经验无法参与参数化复用。

## 验收标准

- 新写入行的 `confidence_score` nonNULL 率 > 0（旧行保持 NULL 是正确状态，不得回填造假）。
- 结构指纹与咽喉票据的 `structure_key` **同函数产出**（grep 证明单源），且 `parse_turn_steps`
  （`objective_evidence.py:53-81`）能吃它——两处形状再次分叉即不合格。
- 检索侧 `min_relevance` 的**可达性重算**：给出新分布下该门打开的实际比例。
  上一批工单 014 踩过"估器下界 ≈0.45 而门槛设 0.5 让门打不到"，本票必须以数据定档，不得凭感觉调。
- 真实库只读；所有写验证在 `tmp_path` / 复制库上（索引全局约束 6）。
- 净 LOC 为正（迁移 + 写侧 + 用例），列明去向。

## 禁区

- 不得把参数明文写进 `context`（隐私 + 体积 + 与结构指纹单源分叉）。

`tests/unit/evolution/experience/test_structure_identity_param_shape.py`：`9 passed`，
含端到端负向（换参数必落两个 `structure_key`）与隐私锁（不落明文）。

订正说明：复核发现 `structure_key` 在此前已吃参数（`{"city":"x"}` 与 `{"city":"y"}`
本就不同哈希），上一轮「参数塌成同一身份」的读数有误；
本票的净改动是**消除第二份实现**，不是「补上参数」。原文与订正见规格文档 8.3。

### 订正（第八轮）：`execution_time` 在**并行轮**仍会落成 NULL

票面要求 `execution_time` 取咽喉已算出的 `elapsed`。串行轮已兑现，但**同轮多条调用
都声明并行安全时**（`loops/base.py` 走 `asyncio.gather`）读数仍为 0.0 ⇒ `or None` 折成 NULL。
根因已定位为 H1（`ContextVar.set()` 只改当前任务副本，而工具在
`ToolCoordinator.run_with_timeout` 的 `ensure_future` 子任务里执行），并附一个独立命中点
H2（`get_turn_tool_elapsed() or None` 用读数真假值回答"测没测到"，把"测到 0.0 秒"折成 NULL）。
两处均按根因收口：轮级耗时改为**轮首绑定的累加器对象**（跨任务按引用共享），
新增 `has_turn_tool_measurement()` 按测量计数回答"测没测到"。
实测与判据见 `tests/unit/evolution/experience/test_turn_elapsed_accumulation.py`（6 条）
与规格文档 §12.2。
