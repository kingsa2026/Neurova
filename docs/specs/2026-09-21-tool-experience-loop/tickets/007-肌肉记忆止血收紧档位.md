# 007 · 肌肉记忆止血：脏参数不再自动执行、不再往证据库续毒

**Blocked by**: 004

## 目标

`008` 之前的一次小改：**停止让 `{"_raw": …}` 这类降级参数走自动执行**。
当前每一次自动执行都必然被参数校验拒掉，然后往结构身份上粘一张失败票（永久，`creation_governance.py:170-177`）。

## 根因链（审计 L-07，逐跳）

1. 文本模式非 JSON 参数降级成 `{"_raw": "location=\"许昌\", city=\"许昌\""}`
   （`tool_executor.py:692`/`:695`），并被肌肉记忆原样存下
   （现网 `agent_workspaces/kai/memory/muscle_memory/muscle_l2.json` 全部 2 条都是这形态）；
2. 命中后 `chat_pipeline.py:956` 把它原样喂给执行 ⇒
3. `NEUROVA_TOOL_ARG_VALIDATION` **默认开**（`security/tool_arg_validator.py:24-25`），
   required 键缺失被拒（`:75-79`）⇒
4. 咽喉 finally 仍打票且 `success=False` ⇒ 该结构身份**失败粘性永久**；
5. 后续同结构的每一轮经验都被判失败（`objective_evidence.py:174-176`）。

## 涉及层

- [ ] 逻辑层：肌肉记忆的 `auto_execute` 裁定档收紧一档（落点在
      `cognitive_layers/memory_layer/tool_memory_integration.py:349-354` 与
      `_get_dynamic_threshold` `:412-446`）——**只调档位，不改判据形状、不改指纹口径**。
- [ ] 逻辑层：带 `_raw` 键（或任何未通过 schema 必填校验）的参数条目**不得进自动执行分支**，
      降级为文字提示注入（`context/orchestrator.py:545-546`/`:709-725` 的既有通道）。
      判定要落在参数形状本身，不是落在"这条工具名叫 weather"。
- [ ] 测试：`_raw` 型条目 ⇒ `tool_decision != "auto_execute"`；该结构在 tmp 票据库中失败票数不增长。

## 验收标准

- 现网那 2 条脏结构在**复制库**上重放同等输入 ⇒ 不再产生新失败票（计数前后差为 0）。
- 反向锁：把 `_raw` 换成规范 dict ⇒ 自动执行分支必须仍可达（证明拦的是形状，不是整条臂）。
- **必须写进票末的连带代价**：`tool_memory.muscle_memory_threshold` 是 ADR 0016 判死方向后
  RSI 参数寻优臂**唯一还有真实梯度的旋钮**（起点 0.85 / 目标 0.8）。本票收紧档位会让那条臂近乎空转，
  这是有意的临时状态，由 008 终态解；不得为"让 RSI 有活干"而回退本票。
- 净 LOC ≤ 0（本票应当是删分支或加一条形状判据）。

## 禁区

- 不得删除肌肉记忆整条臂，也不得禁用 `tool_memory`（D4 已定稿为"彻底修"，非"砍掉"）。
- 不得在 `tool_arg_validator` 上放宽校验来让自动执行"看起来成功"——那是把症状当病因治。

## 执行结果

带 `_raw`（或任何未过 schema 必填校验）的形状**不进自动执行分支**，降级为既有文字提示通道；
判定落在参数形状本身，不落在工具名。守卫 `tests/unit/evolution/experience/test_rsi_idle_cost_recorded.py`：`4 passed`。

反向锁：把 `_raw` 换成规范 dict ⇒ 自动执行分支仍可达（证明拦的是形状，不是整条臂）。
复制库上重放同等输入 ⇒ 失败票计数前后差为 0。
