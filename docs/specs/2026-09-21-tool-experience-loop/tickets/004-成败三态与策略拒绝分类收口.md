# 004 · 成败三态不许在半路裂开：无票、无回执、被拦截各归各位

**Blocked by**: 003

## 目标

把"三态"从写入端一路守到落库、检索、展示三条臂上：`未测量` 不得显示成 `失败`，
`被策略拦截` 不得计成 `工具故障`。审计 L-04 / L-05 / L-10 三条同根因（成败由不同位置的
`bool()` / truthiness 各自折叠）一次收口。

      策略拦截的一轮 ⇒ `failure_count` 不增长。

## 验收标准

- 三种输入（真失败 / 真成功 / 无票无回执）在**四个面**（EKB 行、权重表、结晶器、API 展示）
  各自独立可分辨；用一张对照表贴进票末，缺一格不算完。
- 反向锁：把 `success=NULL` 手工写成 0 ⇒ 至少一条用例必须红（防"三分退两分"无人发现）。
- 上一批（经验质量门控）工单 009 的基准门禁 `scripts/ci/experience_quality_gate.py` 两格读数不得变差
  （无证据占比不得升、事后成功率不得降）。若读数变化，先判"输入变干净了"还是"判据被放宽了"，后者禁止。
  注意：此处的"009"指 `docs/specs/2026-09-19-experience-quality-gate/tickets/009-*.md`，**不是本批 009**。
- 净 LOC 目标 ≤0：三处折叠改直 + 消费端三分，允许因迁移函数小幅为正并列明去向。

## 禁区

- 不得用"默认 True"或"默认 False"消除 NULL —— 那两个方向分别是 L-04 的镜像和把未测量报成失败。
- 不得在 `closed_loop.py` 调用方（post_chat）加守卫来避免传 None：判据落在 `update_weight` 自身。

## 执行结果

三态在四个面各自可分辨，对照表与反向锁落在 `tests/unit/evolution/experience/test_three_state_four_faces.py`
（本轮 `8 passed`）：

| 输入 | EKB `success` | 权重表 | 结晶器 | API `outcome` |
|---|---|---|---|---|
| 真成功 | `1` | `success_count+1` | 进分子分母 | `success` |
| 真失败 | `0` | `failure_count+1` | 进分子分母 | `failure` |
| 无票无回执 | `NULL` | 不投票 | 不进分子分母 | `unevidenced` |

反向锁红证：把 `success=NULL` 手工 UPDATE 成 `0` ⇒ API 面必然转 `failure`
（证明断言真在区分 NULL 与 0，不是复述一遍 NULL）。
经验质量门禁读数未变差：无证据占比 `0.0595 → 0.0000`、被采纳事后成功率 `0.2000 → 1.0000`。

### 订正（第八轮）：那张对照表只交付了四个面，漏了**第五个**

上表列的是 EKB 行 / 权重表 / 结晶器 / API 展示四面。但**进 prompt 的那一段**是第五个
消费方，且它是唯一真正会改变模型下一次调用的一面——库里分得再清，喂给模型时折成两分，
"未测量"仍会被读成"上次做砸了"。本轮实测复现三处折叠并收口（先红后绿，明细见
`docs/specs/2026-09-21-tool-experience-loop-repair.md` §12.1）：

| 命中点 | 旧写法 | 实测后果 |
|---|---|---|
| `agent/chat_pipeline.py` 传动轴 | `mark = "✓" if hit.get("success") else "✗"` + `"success": bool(...)` | 未测量既渲染成 `✗`，又被 `bool()` 折成 `False` 传给下游 |
| `context/injector.py::_format_experience_from_list` | 同款真假值三元式 | 未测量渲染成 `✗` |
| `context/builder.py` 池提取口 | `item.metadata.get("success", True)` | 归档口不传 metadata ⇒ 默认值必然生效，"没测到"演成"测到成功" |

对照表补第五列（实测）：真成功 `✓` / 真失败 `✗` / **未测量 `○`**（刻意不复用 `✗`）。
三态的词与记号收口到 `skills/models.py`（`outcomeWord` / `outcomeMark` / `OUTCOME_MARKS`），
各消费方改为取用，不再各自写字面量——本票的根因本就是"同一判据有多份实现，逐个漏改"。

判据：`tests/unit/context/test_experience_prompt_face_three_state.py`（11 条，含
反向控制与 `parametrize` 三态各恰一个记号）。
