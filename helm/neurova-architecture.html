配置参数

参数 描述 默认值 类型
backend.replicaCount 后端副本数 1 整数
backend.image.repository 后端镜像仓库 neurova/backend 字符串
backend.service.port 后端服务端口 9527 整数
backend.resources.requests.cpu CPU 请求 500m 字符串
backend.resources.requests.memory 内存请求 1Gi 字符串
database.persistence.enabled 启用持久化存储 true 布尔值
database.persistence.size 存储大小 10Gi 字符串
llm.apiKeySecret LLM API 密钥 Secret neurova-llm-secret 字符串
ingress.enabled 启用 Ingress false 布尔值
hpa.enabled 启用自动扩缩容 false 布尔值
