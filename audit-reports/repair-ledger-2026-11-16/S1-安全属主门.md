## P1-1 console.py 聊天面与会话操作面绕过 Agent 属主门

- **条目**：审计 P1-1（含 §11 复核新增命中点 2）。

  （LLM/记忆/额度）。同一 agent 走 `/v1/chat` 403、走 console 200。
- **修复点**：
  - `console.py:158` 新增 `_agentAccessible()`（WS 腿布尔门）与 `_gate_agent_instance()`
    （HTTP 门：实例已装配而身份不可访问即 403；实例未装配维持既有 503/回退语义，不扩大拒绝面）；
  - `console.py:745`（POST /chat，先于会话创建等一切副作用）、`:1320`（chat/review）、
    `:1739`（auto-title）、`:1937`（DELETE /chat/rounds）、`:2247`（POST /chat/feedback，
    一次过门覆盖端点体 :2257/:2272 与 `_apply_feedback_to_memory/channels/crystallizer`
    :2013/:2046/:2079 全部下游取实例点——教义第 5 条同路径一次收口）；
  - `console.py:2557` WS chat 腿：agent 在而 `_agentAccessible(defaultAgentId(), …)` 为假
    → error 帧（不再把无主默认 agent 供任意登录用户对话）。
- **红灯**：`test_s1_ownership_gates.py` 7 项 console 用例全红
  （`test_console_chat_rejects_foreign_agent` 等，实测 403 缺失/门未接线）。
- **绿灯**：41/41 全绿；存量套件经 A/B 后无新增失败。
- **live-verify**：真后端 9527，普通用户令牌 `POST /api/v1/console/chat`（agent_id=default）
  → **403**「无权对话智能体『default』」；admin 令牌流式 → **200** 正常回合。
