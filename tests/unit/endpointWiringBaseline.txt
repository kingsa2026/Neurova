# 未挂载端点模块**处置台账**（Issue #68）· 只降不升
#
# 行格式：`模块短名 | 处置 | 依据`
#
# 收录口径：模块定义了路由（`@router.<verb>`），但装配后的应用里一条都不可达
# ——是「有实现却无挂载点」，不是「挂了零条路由」（后者由 mountedRouterAudit 拦下）。
# 判据单源在 scripts/generate_api_inventory.py 的 unmountedEndpointModules()；
# 守卫 tests/unit/api/test_route_mount_contract_guard.py 双向钉住（新增即红、
# 处置与磁盘事实不符亦红）。
#
# 处置是**有限枚举**，机器可判定（WIRING_VERDICTS）：
#   已接线 ― 该模块现在真在装配后的路由表里；
#   已删除 ― 该模块已不存在（消失的写法只有一种：真的删掉，不是「不注册」）；
#   待实现 ― 保留待接线，必须写明依据（不得留空）。
#
# 逐条处置（本轮收口，2026-09-22）：
#
# computer_api | 已接线 | /computers/* 计算节点管理面。此前未挂载的**根因是身份是假的**
#   ——8 处 `Depends(lambda: "current_user")` 硬编码身份，挂上去等于把计算节点数据
#   对匿名请求开放；且唯一消费方 `NeurUI/src/api/computer.ts` 走裸 axios 绕开唯一
#   实例（无 token、无信封解包），指向未挂载的 `/api/computers`。两处同批收口：
#   身份改真实 JWT `get_current_user`（admin 面另加角色闸），前端回归 `@/api`
#   唯一实例并按 `/api/v1` 请求。挂载点 `/api/v1/computers`。
