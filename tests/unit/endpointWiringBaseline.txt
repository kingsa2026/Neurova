# 未挂载端点模块**处置台账**（Issue #68 / #112 后续）· 只降不升
#
# 行格式：`模块短名 | 处置 | 依据`
#
# 布局纪律：台账行必须集中在文件**头部**，正文注释不得插在行之间再回头续行。
# 写入侧 (`_wiringRows()` → `readWiringBaseline()`) 只认「首个非空行」起的一段连续行，
# 注释插进行间会把后续台账行挤出基线，取数与台账对不上（本轮冲突即由此形态放大）。
#
# 收录口径：模块定义了路由（`@router.<verb>`），但装配后的应用里一条都不可达
# ——是「有实现却无挂载点」，不是「挂了零条路由」（后者由 mountedRouterAudit 拦下）。
# 范围是**全仓**（scripts/generate_api_inventory.py 的 SOURCE_ROOTS），不是只扫端点包：
# 口径若比声明窄，同一形态在包外就永远看不见，连被登记的机会都没有。
# 自带 FastAPI() 应用的模块不在内——它由自己的进程服务，不是孤儿。
# 条目用**完整点分模块路径**（末段短名不保证唯一，作台账键会有歧义）。
# 判据单源在 scripts/generate_api_inventory.py 的 unmountedEndpointModules()；
# 守卫 tests/unit/api/test_route_mount_contract_guard.py 双向钉住（新增即红、
# 处置与磁盘事实不符亦红）。
#
# 处置是**有限枚举**，机器可判定（WIRING_VERDICTS）：
#   已接线 ― 该模块现在真在装配后的路由表里；
#   已删除 ― 该模块已不存在（消失的写法只有一种：真的删掉，不是「不注册」）；
#   待实现 ― 保留待接线，必须写明依据（不得留空）。
#
# 本批销账（不再计入「待实现」，防复活守卫
# tests/unit/api/test_orphan_faces_retired_guard.py）：
#   skill_market / skills_market —— ADR 0013 裁定的待删两套，已按该 ADR 删净；
#   neurova.api.openplatform.routes —— 第二份开放平台面（19 条路由、零消费者、
#     整条 router 无 Depends），与在用的 endpoints/openplatform_keys.py 同名不同物；
#   neurova.core.acp_server —— 第二份 ACP 会话面（chat_stream 为模拟实现、默认
#     模型表是幻影条目），在用的是 endpoints/acp_api.py + agent/protocols/acp_runtime.py。
# 四条都属「第二份平行实现」而非「待接线」：补接线只会让同一件事有两个写入点，
# 补鉴权只是给第二份面加把锁（教义第 6 条：在产生第二份事实源的一侧删除）。
#
# 逐条处置理由（不许静默）：
#
# computer_api | 已接线 | /computers/* 计算节点管理面。此前未挂载的**根因是身份是假的**
#   ——8 处 `Depends(lambda: "current_user")` 硬编码身份，挂上去等于把计算节点数据
#   对匿名请求开放；且唯一消费方 `NeurUI/src/api/computer.ts` 走裸 axios 绕开唯一
#   实例（无 token、无信封解包），指向未挂载的 `/api/computers`。两处同批收口：
#   身份改真实 JWT `get_current_user`（admin 面另加角色闸），前端回归 `@/api`
#   唯一实例并按 `/api/v1` 请求。挂载点 `/api/v1/computers`。
#
# cost_api | 已删除 | `/cost/*` 成本查询面。挂上去只是**并行第二份成本读面**：
#   现行成本看板走 `modules/cost.ts` → `/api/v1/cost-rollup/*` + `/api/v1/budgets/*`
#   （Issue #121 已归位、实测可达），与本模块的 `/cost/agent|company/*`、`/cost/calculate`
#   逐条重叠而口径不同。唯一调用方是与 computer_api 同一份 React 原型。
#   教义第 6 条：同域两名并行读面是待收口项，不是待接线项。
#
# migration_api | 已删除 | `/migrations/*` 零调用方，且底层
#   `neurova/storage/zero_downtime_migration.py` 的 7 阶段实现**全是 pass**
#   （`_enable_dual_write` / `_insert_into_new_schema` / `_switch_readers` /
#   `_schedule_cleanup`），`rollback_migration` 恒 False、`verify_migration` 恒 True。

#   能力」。端点面与那个桩实现同批删除：诚实的形态是能力不存在，而不是提供假接口。
#   真实 schema 演进的唯一入口是 `neurova/core/db_migration.py`（PRAGMA user_version
#   注册表，已有 6 个消费域）。

#   端点无客」。此前该面**零挂载且零鉴权**：挂上去即匿名可改全局运行态。
#   本批补身份闸口（`APIRouter(dependencies=[Depends(get_current_user)])`），
