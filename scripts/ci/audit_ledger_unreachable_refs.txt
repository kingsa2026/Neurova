# 为什么要有这一份，而不是把号从文档里删掉：删掉即抹掉证据——这些笔真的发生过，只是被并发
# 会话重写历史带走了身份。也不留成「机器不管」：每一行都得写清为什么无法安全回写，
# 判据双向咬合——
#   ① 现场有不可达号而未在此署名 → 红（不许静默遗留）；
#   ② 此处的署名行已不成立（号已回到主线，或该号的对象在、却不是 commit）→ 红（该行须删）。
#      「本克隆连对象都没有」**不算**不成立：并发重写撤账的笔只剩在写它的那台机器上，
#      干净克隆看不见载体是常态，也正是本清单存在的理由（见 `signatureExpired()`）。
#
# 口径：`<8 位短号> <理由>`，注释与空行不算条目。理由必须是**复算出来的读数**，不写猜测。
