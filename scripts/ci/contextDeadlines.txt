# ① **判据类**（第 2 列）：机器算出来的直接可达性，**不得人填**。
#    器械单源在 scripts/ci/context_deadline_ledger.py 的 classify()，四值：
#      absent      ― 生产侧无定义、无赋值（符号不存在或已删除）
#      no_consumer ― 有定义/赋值，但生产侧零消费点
#      self_loop   ― 有定义，消费点全落在自己定义文件内（无外部消费者）
#      consumed    ― 有定义，且存在跨文件消费点
#    台账值与算出来的不一致 → 守卫报红。人改台账去迎合等于把判据降级成自述。
# ② **处置**（第 3 列）：人对该条的决定，有限枚举、机器可判定：
#      待处置      ― 尚未动（本批 B6 全部条目的当前状态）
#      已接线      ― 补上真实消费点（或消费点已修好）
#      已删除      ― 从仓库消失（真的删掉，不是「不注册」）
#      收口第二份  ― 同契约存在两份实现，收口到一份并删净另一份
#
# 判据类**只算 1 跳**，不做传递可达性：「1 跳可达但其消费方自身不可达」
